# iStudio UI-3

按参考图（小齐 UI 设计师的「后台 UI 设计」）做的第四套界面，方向是**黑白主题 + 极少量彩色点缀**。

本版只交付**生成页**，登录页顺带改成同一套语言（侧边轨道的其它入口标为待设计）。

| 路径 | 页面 |
| --- | --- |
| `/` | **生成页**（首页即生成页，`?mode=` `?task=` `?prompt=` 可直接带参进入） |
| `/login` | 登录 / 注册 |

## 从参考图里取的语言

| 参考图的手法 | 落点 |
| --- | --- |
| 选中态是**黑色药丸** | 通用生图 ↔ 电商工具、四个商品任务、登录/注册、画面比例、风格 |
| 白卡片 + 1px 细描边 + 极轻阴影 | 所有卡片；底色是纯中性浅灰，不带色相 |
| 左轨图标 + 黑色圆角方块选中 | 左侧导航；未选中是透明底 |
| 右浮竖向工具坞 | 画布右侧的缩放 / 适应 / 预览胶囊，窄屏自动横排到底部 |
| 步骤条（绿点 + 连线） | 生成中的进度：已提交 → 排队中 → 生成中 → 完成 |
| 卡片右上角圆形箭头按钮 | 「更多设置」用它可以展开 / 收起 |
| 大号数字 + 小号灰标签 | 比例读数、像素尺寸、张数都用 tabular-nums |

## 布局

生成页是**铺满视口**的：没有外框留白，左侧图标轨道贴左边、顶部导航贴顶边，
内容和窗口边缘之间只有 20px 的内边距。原来那层「悬浮卡片」的圆角外框已经去掉，
只保留内容区左上角一层极淡的柠檬光晕，避免整页死白。

内容区自上而下是：**页面标题行**（标题 + 一句话说明 + 右侧工单规格 chips）、
**设置卡片列**（01 素材 / 02 描述 / 03 画面 / 更多设置 + 吸底的生成按钮）、
**画布**（无标题的纯工作面 + 右浮工具坞）。

登录页不同 —— 它是居中表单，所以仍保留页面底色和玻璃外框。

## 几个刻意的细节

- **页面标题行**给整页一个层级锚点，标题 23px，是页面上最大的字号；右侧 chips 显示
  比例、分辨率、真实像素，以及「产出 N 张 / 已出 N 张」（有结果后自动切换成实际张数）。
- **空画布不空着**：给三个起步示例（薄荷 / 柠檬 / 蜜桃各一枚），点一下直接填进描述框。
- **生成按钮下方一行**只放模型名 —— 这是唯一没在别处出现的参数；右侧是
  `⌘/Ctrl + Enter` 快捷键提示，实际也支持，和点按钮等价。
- **画布卡片没有标题栏**，标题归到页面标题行，画布只留纯工作面，避免同一句话出现两次。

## 配色

主题就是黑白，彩色分成三层，各自职责明确：

**① 区块级（最大面积，只有一处）**

- 素材投放区整块用薄荷打底 + 薄荷虚线边，是设置列里唯一的彩色区块。

**② 流程级（三个步骤各一档柔和色）**

- 步骤徽标：`01 素材` 薄荷、`02 描述` 柠檬黄（实底，聚焦点）、`03 画面` 蜜桃。

**③ 状态与强调（小面积）**

- **柠檬黄 `#d7f24b`** —— 唯一的强调色：导航选中项的小圆点、画布上的「参考样张」小标、
  「已出 N 张」胶囊、生成中的进度条与当前步骤节点，同时是文字选中色。
- **薄荷 / 蜜桃 / 珊瑚** —— 状态语义：完成（薄荷）、部分失败（蜜桃）、失败与错误（珊瑚）。

压在彩色照片上的角标一律保持中性白底，保证可读性 —— 那里的颜色交给照片本身。

其余全部是中性的：底色 `#f3f4f6`、卡片 `#ffffff`、描边 `#e9ebef`、墨阶 `#111214`，
选中与主操作用近黑 `#0e0f11`。阴影是中性的低透明度冷灰，不做颜色装饰。
背景左上角有一层极淡的柠檬光晕，作为整页唯一的环境色。

生成模型、分辨率、生成数量等参数仍在「更多设置」里，只是不再单独占一张摘要卡。

## 与后端的契约

与 `apps/web`、`ui`、`UI-1`、`UI-2` 使用同一套契约，业务语义没有改动：

- `lib/contracts/generation.ts` —— 生成输入的 zod 校验（与 Go 端字段一一对应）
- `lib/api.ts` —— API 基址、资产上传、错误读取
- `components/workbench/use-generation-task.ts` —— 提交、轮询、历史结果

比例选项从 `aspectRatioSchema` 派生，界面上不会出现后端会拒绝的比值。
校验失败会显示到具体字段，而不是 `Invalid input`。

## 本地运行

```bash
cd UI-3
pnpm install
cp .env.local.example .env.local   # 按需改 NEXT_PUBLIC_API_BASE_URL
pnpm dev                            # http://127.0.0.1:3300
```

## 校验

```bash
pnpm typecheck
pnpm test
pnpm build
```

## 无障碍与动效

- 图标按钮都有 `aria-label`，分段控件用 `aria-pressed`，状态用 `role="status"`
- 焦点环是 2px 近黑描边；画布、设置列、工具坞都能 Tab 到达
- 动效只用 `transform` / `opacity`，曲线统一 `--ease-out` / `--ease-in-out`
- `prefers-reduced-motion` 下全部动效收敛为即时
