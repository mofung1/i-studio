# iStudio 开发进度

本目录用于持续记录正式项目每次开发实现的功能、改动范围、验证结果、阻塞项和待产品确认事项。

## 记录规则

- 每个可独立验收的开发批次创建一份编号文档，命名为 `YYYY-MM-DD-NNN-主题.md`。
- 文档状态使用：`进行中`、`已完成`、`受阻`。
- 每份文档必须包含目标、实现内容、文件范围、验证结果、遗留问题和下一步。
- AI 供应商、计费数值、存储期限等需要产品决策的事项单独列在“待确认”中，不在代码里硬编码。
