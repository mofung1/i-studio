# 014 Web 运行时恢复

> 日期：2026-09-09  
> 状态：已完成

## 问题

Next.js 开发服务热更新过程中出现 `Palette is not defined` 和 CSS 解析/缓存错误，首页返回 500。

## 处理

- 检查开发服务日志，确认源码编译状态。
- 清理 `apps/web/.next` 和 coverage 构建产物。
- 重新启动 `pnpm dev:web`。
- 未发现当前 CSS 文件仍存在多余大括号；错误属于热更新缓存残留。

## 验证

- `curl http://127.0.0.1:3000/` 返回 HTTP 200。
- 首页可正常编译，保留项目、灵感、模型选择等内容。

## 约束

开发服务运行期间不要执行 `pnpm build`；需要生产构建时先停止 dev 服务，构建后再清理 `.next` 并重启开发服务。
