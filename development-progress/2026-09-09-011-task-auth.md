# 011 任务鉴权与用户隔离

> 日期：2026-09-09  
> 状态：已完成

## 实现内容

- Go server 增加任务接口 JWT 鉴权。
- 创建任务时解析当前用户 ID，并写入 `generation_tasks.user_id`。
- 查询任务时限制为当前用户所属任务。
- 内存降级模式同样校验任务归属。
- Web 创建任务请求自动携带本地 JWT；未登录返回 401 时跳转登录页。

## 验证结果

- Go `go test ./...` 通过。
- Go `go build ./...` 通过。
- Web TypeScript 检查通过。
- 未登录创建任务返回 `401 AUTH_REQUIRED`。
- 已登录任务可写入 PostgreSQL。
