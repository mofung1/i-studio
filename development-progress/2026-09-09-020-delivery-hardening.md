# 020 交付级主链路、安全与 QA 加固

> 日期：2026-09-09  
> 状态：已完成

## 实现内容

- 修复工作台使用伪素材 ID 的核心断点，改为先上传真实商品图/参考图，再创建生成任务。
- 修复 `projectId` 被前端契约静默剔除的问题，项目归属可完整写入任务与资产。
- 将用户素材读取并内联传给 Gemini 图片模型，使用同步 `generateContent` 接口并兼容 URL/Base64 结果。
- 增加任务列表、安全私有图片加载、结果下载、生成后跳转和终态停止轮询。
- 增加服务端生成参数校验、用户名约束、令牌过期校验、请求体限制和 HTTP 超时。
- 增加项目与资产用户归属校验，移除 URL 查询参数令牌，阻止跨用户资源绑定。
- 增加文件真实 MIME 校验、失败清理、生成结果内容校验和 Redis 降级队列消费修复。
- 未配置 AI Provider 时返回明确错误，前端在上传素材前阻止提交。

## 端到端验收

- PostgreSQL 与 Redis 容器健康启动，API 数据库状态为 `ready`。
