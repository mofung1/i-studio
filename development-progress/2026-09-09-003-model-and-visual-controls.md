# 003 模型选择与生成参数视觉升级

> 日期：2026-09-09  
> 状态：已完成

## 实现内容

- 统一模型枚举：`gpt-image-2`、`gemini-2.5-flash-image`、`gemini-3.1-flash-image`、`gemini-3-pro-image`。
- 首页新增模型、画面比例、分辨率选择，并通过查询参数传递到工作台。
- 工作台模型、比例、分辨率改为受控选择，提交任务时写入真实 payload。
- API capabilities 返回可选模型列表。
- 首页输入框增加 `focus-within` 光效和更明确的聚焦反馈。
- 电商工具卡片增加 hover 位移、阴影和背景层次。
- 配置区控件统一高度、圆角、对齐和焦点样式；模型按钮增加“模型”文字提示。

## 验证结果

- `pnpm build` 通过。
- contracts 与 API 类型编译通过。
- 未调用 AI 接口，无需 API Key。
