# 026 UI 优化与单色设计系统回归

> 日期：2026-09-16  
> 状态：阶段 0-2 已完成，阶段 3 待启动

## 目标

- 回归 `UI/DESIGN-SYSTEM.md` 的 Monochrome AI Workspace 视觉规范，清除绿色 accent 与粉彩卡片。
- 收敛设计令牌（色、字阶、间距、圆角、阴影、z-index），消除散乱硬编码色值。
- 清理 CSS 与组件死代码，合并重复选择器与分散的媒体查询。
- 补齐加载、空、错误、失败等界面状态，消除图片静默加载失败。
- 拆分 729 行工作台巨石组件，补齐移动端导航与可访问性缺口。

## 基线决策（2026-09-16 已确认）

1. **回归单色规范**：现有绿色 accent 与粉彩色视为偏离规范的误入，不是品牌方向。
2. **以现状实现为准**：`DESIGN-SYSTEM.md` 与 `docs/PRD-AI电商创作平台-MVP.md` 均已过时，不顺手改回 PRD。不恢复 025 批次删除的项目概念，不改任务集（保持 商品主图 / 详情页 / 爆款复刻 / 产品精修），不改导航信息架构。
3. **方案先行**：每个阶段先出文件级改动点与验收方式，确认后再实施。

- 像素级回归：`/assets` 0.00%；`/workbench` 差异 0.52%（阶段 0 后新增 loading 图标与 42px 按钮所致）；`/` 仍为 Unsplash 噪声底 5.09%。
