# iStudio UI-2

第三套前端界面，方向来自两张参考图的共同语言：**浅色雾面 + 玻璃大容器 + 大圆角 + 柔和彩色点缀**。
和 `UI-1`（灯箱与工单：中性、精确、宋体、朱砂）是两个完全不同的方向。

本版按你的要求只交付两页：

| 路径 | 页面 |
| --- | --- |
| `/` | **生成页**（首页即生成页，`?mode=` `?task=` `?prompt=` 可直接带参进入） |
| `/login` | **登录 / 注册**（同一页用分段控件切换） |

侧边轨道里的「精修 / 素材库 / 灵感」保留位置但标记为待设计，避免做出假的入口。

## 设计语言

| 取自参考图的手势 | 在界面里的落点 |
| --- | --- |
| 雾面渐变底 + 玻璃大容器 | 整个应用是一块浮在近白底 + 极淡柔光上的圆角玻璃板 |
| 图标轨道，选中项是深色圆角方块 | 左侧导航；未选中是白底胶囊 |
| 数据摘要条 | 设置列顶部的「工单摘要」：模型 / 画面 / 产出 |
| 胶囊分段控件 | 通用生图 ↔ 电商工具（白色胶囊）、四个商品任务（深色胶囊） |
| 大圆角软阴影卡片 | 素材、描述、画面、更多设置四张卡 |
| 彩色只做点缀 | 春绿主色，琥珀（部分失败）、玫瑰（错误） |
| 大号粗体数字 | 摘要条、比例读数、像素尺寸、张数都用 tabular-nums |

配色：**干净的近白底 + 单一绿主色，不使用蓝紫色**。
底色是中性浅灰白 `#f5f7f6`，只叠三团极淡的环境柔光（薄荷 `#ddf3e8` / 奶油 `#fdf3e6` / 中性 `#eaefec`）；
卡片纯白，墨阶是中性近黑 `#161a18`（不带蓝也不带黄），主色春绿 `#0e9f6e`。
最重的渐变只留给生成按钮：`linear-gradient(118deg,#0d8f63,#0a7a54,#086848)`——
白字对比度 ≥ 5.4；摘要条和登录页装饰面板这类大面积用浅绿底配深墨字，把重音集中在唯一的主操作上。
阴影是中性的低透明度冷灰，不做颜色装饰。

## 和后端的关系

与 `apps/web`、`ui`、`UI-1` 使用同一套契约，没有改动业务语义：

- `lib/contracts/generation.ts` —— 生成输入的 zod 校验（与 Go 端字段一一对应）
- `lib/api.ts` —— API 基址、资产上传、错误读取
- `components/workbench/use-generation-task.ts` —— 提交、轮询、历史结果

比例选项从 `aspectRatioSchema` 派生，界面上不会出现后端会拒绝的比值。
校验失败会显示到具体字段，而不是 `Invalid input`。

## 本地运行

```bash
cd UI-2
pnpm install
cp .env.local.example .env.local   # 按需改 NEXT_PUBLIC_API_BASE_URL
pnpm dev                            # http://127.0.0.1:3200
```

## 校验

```bash
pnpm typecheck
pnpm test
pnpm build
```

## 无障碍与动效

- 图标按钮都有 `aria-label`，分段控件用 `aria-pressed`，状态用 `role="status"`
- 键盘焦点环 2px 紫罗兰描边；设置列和画布都可 Tab 到达
- 动效只用 `transform` / `opacity`，曲线统一 `--ease-out` / `--ease-in-out`
- `prefers-reduced-motion` 下全部动效收敛为即时
