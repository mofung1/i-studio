# 全局表单确认提示清理（2026-10-26）

## 调整结果

- 普通表单的保存、关闭、取消、页签切换、导航和刷新不再使用浏览器 `alert` / `confirm` / `prompt` 或未保存离开拦截。校验与请求结果继续在当前表单内显示。
- AI 服务 / 图片反推页签切换保留当前反推草稿；系统提示词来回切换保留各模板草稿。草稿仅在当前页面内暂存，刷新或离开不保留，不新增自动保存。
- 系统提示词「恢复默认」改为「填入默认内容」，只填写编辑器，点击保存后才写入后台。分类、公共灵感与私有提示词编辑直接关闭，不再追加放弃修改确认。
- 删除 AI 服务、停用账号以及渠道和模型的真实生图测试使用统一站内确认框；启用账号直接执行。已有私有提示词等删除确认沿用此组件。
- 确认框使用现有主题和 Radix Dialog，补充后果 / 费用说明与图标，按钮右对齐；支持 Escape 取消、焦点限制与回到触发按钮。模型编辑器内的收费确认只关闭内层。
- 增加源码 AST 回归，检查产品代码不再引入原生 JS 弹窗或 `beforeunload` 拦截。
