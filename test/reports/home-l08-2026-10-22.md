## 服务端与 SEO

新增 `web/scripts/check-marketing.mjs` 和 `pnpm check:marketing`。使用现有 jsdom 开发依赖解析实际 HTTP HTML，不执行页面脚本，不访问生图或写入接口。生产构建下分别检查两种配置：

- 预览：`SITE_ENV=preview`，无有效正式域名。六个营销页保持 `noindex, nofollow`，没有 canonical、OG 绝对 URL、分享图绝对 URL 或生产 JSON-LD；robots 禁止抓取，sitemap 为空。
- 合成正式配置：`SITE_ENV=production`，以 `https://seo-fixture.istudio-acceptance.cn` 作为测试字符串。仅通过 `127.0.0.1:33141` 请求本机响应，没有 DNS 查询或访问该域名，没有把它写入业务配置。六个营销页允许收录，canonical、OG/Twitter 分享图、sitemap 和 Organization/WebSite JSON-LD 指向同一 origin，分享图片在本机服务返回 200。

两种配置均通过：

1. 首页和五个工具页 HTTP 200，各有一个 H1、独立 title/description、连续标题层级、描述性 alt、尺寸信息或 fill 预留布局。主要正文、FAQ 与工具页内链出现在原始 HTML。
2. 使用普通 UA 与智能手机 Googlebot UA 请求，主要正文、title、description 和 robots 一致。没有用交互后加载替代主要文字。
3. 六页页脚保留五个独立工具页链接；跳过导航目标存在且可聚焦，无重复 ID 或缺失的本页片段目标。
4. `/studio`、`/workbench`、`/account`、`/assets`、`/tasks`、`/prompts`、`/settings`、`/login`、`/admin/login`、`/inspiration` 保持 `noindex, nofollow` 且无 canonical，未进入 sitemap。重定向路由按最终页面检查。
5. 旧首页创作参数仍以 307 保留参数重定向到工作台。灵感广场继续暂缓收录。

运行方式见 [SEO 说明](../../docs/seo.md)。测试数据保存于本地忽略目录 `test/artifacts/home-l08-2026-10-22/seo-preview.json` 和 `seo-production-fixture.json`。

使用本地生产构建及独立公开配置服务，通过 Codex 内置浏览器检查。这里的“手机”表示响应式视口，不是实机或完整设备模拟。

| 检查                                      | 结果                                                                              |
| ----------------------------------------- | --------------------------------------------------------------------------------- |
| 六个营销页 × 320、390、768、1024、1440px  | 30 组页面宽度均未超过视口；主要内容和 FAQ 数量保留                                |
| 首页 375×812、844×390、1024×620、1280×720 | 无横向溢出；横屏回到自然文档流；低屏高桌面创作说明在场景范围内                    |

| 五个工具键盘选择                          | 聚焦对应工具链接时选择正确预览，只有一个预览面板可获得键盘焦点                    |
