# 左侧创作面板与多图布局验证

左侧面板改为独立的悬浮区块，描述、参考图片和模型参数纵向排列；费用与生成按钮常驻底部，生成与查看历史时不再自动收起面板。多张参考图片继续使用堆叠、展开、排序及收起交互。

使用真实页面组件与本地模拟结果进行浏览器验证，没有调用生图服务。临时预览路由已移除，验证源文件和截图保存在忽略的 `test/artifacts/floating-creator-ui/`。

| 场景 | 结果 |
| --- | --- |
| 1280 × 720，4 张完成结果 | 主图与右侧最近生成列表独立布局，支持逐张切换及列表滚动 |
| 1024 × 768，4 张完成结果 | 修复旧双列规则造成主图宽度为零；最近生成改为底部横向列表 |
| 1024 × 768，生成 4 张 | 左侧面板保持显示，右侧生成状态与张数正常 |
| 375 × 812，4 张完成结果 | 可切换缩略图，单版本不重复展示最近生成列表，无横向页面溢出 |
| 横竖混合结果 | 768 × 1024 竖图与 1366 × 768 横图均按实际比例适配；手机横图显示约 327 × 183.84 |
| 3 张参考图片 | 堆叠数量、展开、收起正常；展开后从第一张开始，避免自动聚焦导致首图被裁切 |
| 深色模式、长描述、手动收起 | 主题变量生效，输入区与参数可滚动，底部操作区保持可访问 |
