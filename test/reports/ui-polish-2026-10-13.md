# 工作台 UI 打磨记录 · 2026-10-13

沿用现有黑白工作台的导航、主题与紧凑生图布局，重点改善新功能衔接、表单一致性、内容可见性及错误恢复。

## 已实施

- 图片反推在 AI 生图、发现灵感、我的资产共用同一个弹窗，按需加载。桌面图片和提示词并排，小屏上下排列；头部与底部操作保持可见，正文独立滚动。手机完成分析后定位到提示词区域。
- 默认只显示主要提示词，补充要求、详细画面分析按需展开。初次分析使用主要按钮，已有结果后的重新分析降为次级操作，应用到生图保持主操作。
- 语言、历史记录、分类与其他页面共用下拉组件，弹窗中的菜单保持在弹窗层级内。历史显示文件名、模式、状态和时间，避免相同图片的记录难以区分。
- 双语编辑独立保留；重复提交有保护。追加/替换后可撤销；用户在 AI 优化等待时手动修改描述，返回结果不再覆盖新文字。重新分析或切换记录时明确保护已编辑草稿。
- 提供实际分析状态、取消、手动清除、未配置服务的设置入口以及读取失败后的重载入口。关闭弹窗和换页不会取消后台任务，刷新可恢复未过期草稿。
- 资产图片预览提供原提示词、图片反推、下载三个清晰操作；原记录与重新识图分开。保存灵感默认草稿，封面使用需勾选，分类可就地新增。
- 修正深色主题的输入占位文字颜色，输入焦点使用内描边，避免边框被裁切。设置字段关联名称与说明，设置标签支持方向键定位与 Enter 激活。
- 增加局域网/普通 HTTP 环境的复制回退；失败时保留可手动复制文本。私有图片缓存按登录会话隔离，切换账号同时清除弹窗内存与草稿来源，避免上一账号内容残留。

## 页面与验证

检查范围：AI 生图、电商工具、服装组图、发现灵感、管理提示词、分类管理、我的资产、AI 设置。产品页面检查 375 / 1440 宽度、浅色与深色主题；反推弹窗额外检查 768 宽度和固定底部操作。深色检查断言页面实际处于深色主题，避免只验证了切换按钮。

Chrome 浏览器流程验证覆盖上传原图及分析图、双语编辑复制、追加撤销、风格默认不带原图、重新分析确认、取消、切页恢复、刷新草稿、分类新增和草稿保存、设置保存、自定义模板、历史切换确认、清除记录、本人资产入口、HTTP 复制回退与跨账号重置。验证完成，无页面 JavaScript 错误或横向页面溢出。

以上写接口均使用模拟数据：真实业务写入与付费调用为 0。真实识图验证单独记录于 [识图效果记录](prompt-reverse-evaluation-2026-10-13.md)。前端 34 项测试、类型检查及生产构建通过；后端开启隔离 PostgreSQL 的 `go test -race ./...` 和 `go vet ./...` 通过。

## 本次边界

保留已确认的紧凑底部输入框、提交折叠和右侧逐图最近生成布局。没有为新功能增加一级导航，也没有改动个人工作台的共享配置规则。当前验证针对桌面 Chrome 和模拟手机视口；真实 iOS/Android 输入法与浏览器仍需设备验证。

## 图片反推配置改版

根据使用反馈，配置页改为一个统一的表单面板，按识图服务、分析偏好、结果保留分区；桌面标签与控件对齐，手机按区块排列，设置导航保持单行。服务选择显示实际模型和识图能力；细节档位用三张单选项呈现，时间输入带单位，保留时长提供 24 小时、3 天、7 天快捷选项。

补充管理 AI 服务、编辑对应反推模板、恢复推荐配置入口。保存状态集中在底部，保存期间禁止重复提交和切换设置标签；数字字段可正常清空并按范围校验，失败保留当前编辑，读取失败可就地重试。

使用隔离的模拟配置 API，通过浏览器验证参数切换、服务筛选、保存/失败状态、推荐值恢复、输入校验、读取重试及模板导航。检查手机与桌面、浅色与深色主题，无横向页面溢出；手机主要操作为 44px 点击区域，选项标签无遮挡。模拟写入不改变真实配置，不调用 AI；验证结束删除临时预览路由并停止预览服务。

正式构建后使用已有测试账号只读打开配置页，确认实际服务信息和新布局已上线，浏览器无错误日志。未修改真实配置，随后退出测试账号并关闭验证页。
