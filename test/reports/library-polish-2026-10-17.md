# 圆形配置入口与个人库调整（2026-10-17）

## 已实现

- PC 创作配置收起后显示 48×48px 黑底白图标的圆形入口，保留原停靠位置、点击展开、焦点恢复和状态反馈。生成中显示白色进度图标；错误保留红点与完整状态描述。减少动态效果偏好下停用按压过渡。
- 资产页固定视图、项目分类、搜索和筛选栏，作品、素材、任务记录共用可聚焦的独立内容滚动区。筛选条件变化时回到顶部，加载更多和已有弹窗流程保持不变；手机同样采用记录内容滚动。
- 移除资产页模型名称筛选及对应查询参数，参数详情仍显示任务原本使用的模型。
- 资产与提示词页的搜索、工具/分类/排序下拉使用面板底色：日间白色，深色主题跟随语义面板色。

## 电商入口方案

尚未替换正式电商主页，先提供三个可交互方案供选择：

- **动态工具矩阵（推荐）**：按工具展示专属图形与轻量悬停动效，新增功能直接扩展网格。
- **聚焦工作台**：左侧选择工具，右侧查看大图和说明，再进入操作；介绍更充分，多一步选择。
- **紧凑工具目录**：每行一个工具，小型动态图形配清晰文字，适合快速查找与较多工具。

三个方案都支持从五项扩展到十项的布局预览，新增项标明示例。桌面 1024px 测得三版均为 1390px 高且无横向溢出；390px 下十个工具的矩阵同样无横向溢出，选项切换和预览交互正常，无脚本错误。

截图、合成数据夹具与方案片段归档在 Git 忽略目录 `test/artifacts/library-polish-2026-10-17/`。未访问真实私有资产、提交生成或调用付费 AI。

## 后续调整：白色自由悬浮入口

- PC 收起入口改为白底黑图标、48px 圆球，悬浮在内容区上层，画布释放原有入口占用列；AI 生图和电商工具共用同一交互。
- 直接拖动保留抓取偏移，松手原地停留；6px 内的轻微移动仍按点击处理，完成拖动不会误触展开。展开再收起保留本页面内的位置，恢复默认布局清除位置。
- 位置限制在可见内容区内，留 8px 边距；窗口与画布大小变化会重新约束。Esc、失去焦点或指针取消可撤回本次拖动；方向键移动、Shift 加速、Home 复位，Enter/Space 保留原有按钮操作。
- 浏览器验证：1280×720 白底 rgb(255,255,255)、黑色图标 rgb(17,17,17)；初始 x=256/y=104，拖至 x=978/y=498 后保持收起，再展开和收起位置不变。右下边界为 x=1208/y=648；缩小到 1024×600 后仍在可见范围内。
- 电商工具右侧停靠收起后，圆球初始 x=1208/y=104，画布 x=248/宽1016；390×844 手机上保持完整配置且无横向溢出。
- 42 个测试文件、172 项测试通过，包括新增的拖动、点击防误触、边界、取消、键盘与位置保留回归。实际页面截图归档：`test/artifacts/creator-orb-2026-10-17/floating-orb.png`。
