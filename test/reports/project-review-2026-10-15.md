## 前后台独立账号

| 项目 | 前台 | 后台 |
| --- | --- | --- |
| 账号表 | `users` | `admin_users` |
| 登录页面 | `/login` | `/admin/login` |
| 登录 API | `/v1/auth/login` | `/v1/admin/auth/login` |
| 会话查询 | `/v1/auth/me` | `/v1/admin/auth/me` |
| 会话用途 | `aud=web`，7 天 | `aud=admin`，8 小时 |
| 浏览器存储 | `istudio-access-token` | `istudio-admin-token` |
| 创建方式 | 前台注册 | `server/.env` 或部署命令 |
| 数据范围 | 本人资产、提示词、任务和积分钱包 | 平台配置、用户状态与余额管理 |

允许同名账号，密码在各自的表中独立维护；两端登录与退出互不替代。后台账号不能拿后台令牌调用前台资产、生图或个人提示词接口。前台会话不能用于后台，包括历史管理 API。前台用户管理删除“设为管理员”操作。

旧管理员通过 `010_admin_identity.sql` 一次性拆分：复制后台身份与密码哈希，保留原前台账号、资产、钱包及流水，并将其前台角色改为普通用户。初始密码沿用旧值，之后独立更改。迁移可重复运行，旧共享会话必须重新登录。环境管理员的更名、改密只更新后台身份，不再修改同名前台账号，也不为管理员自动创建钱包。

前台反推结果继续保存为个人提示词；移除反推弹窗中失效的公共灵感发布表单与关联样式。后台不能从前台私有反推任务读取封面图片。
