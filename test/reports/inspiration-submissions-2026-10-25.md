# 提示词投稿、人工审核与积分奖励验收

日期：2026-10-25。已完成开发、隔离验收及本机 API / 前端更新。

## 范围

- 发现灵感增加分享与我的投稿入口，个人提示词可带入投稿表单。
- 提交文字、公共分类、效果封面、参考图要求及使用说明，确认通过后公开。后台可通过、退回、调整分类和下架。
- 私人投稿、版本与公共内容分开保存；未通过版本的文字及图片只对本人和管理员开放。新版本重新审核，已通过旧版可继续公开。
- 审核时默认不奖励，勾选后填写整数数量。事务同时提交发布、余额、奖励流水和审核日志；行锁、版本校验及唯一流水编号保证单条投稿只奖励一次。
- 默认开放投稿、每天每人 5 次；后台可关闭或设置 1–100 次。新建和修改共用额度。
- 封面独立保存并计入额度，最长边 1280px、JPEG 编码，保留原素材；社区公开图片接口检查上架状态且禁用长期缓存。

具体规则及接口见 [功能文档](../../docs/inspiration-submissions.md)。

## 实际页面验收

使用 44020 / 33020 的独立 API、独立前端副本和 `istudio_submissions_preview_20261025` 数据库；虚构作者、审核员和观察账号，不使用业务账号。封面取自项目现有公开概念展示图，未新生成图片；隔离 API 的 AI 配置为未配置。

1. 作者填写标题、提示词、分类与使用说明，从素材选择器选择自己的图片并确认公开，提交后显示待审核。
2. 审核员查看完整文字和封面，勾选奖励 12 积分并通过；公开库出现一条投稿，作者可用余额从 0 变为 12，流水只有一条投稿奖励。
3. 作者保留原封面修改为版本 2，进入待审核，版本 1 继续公开；后台版本 2 的奖励选项禁用。
4. 管理员退回版本 2 并填写原因。本人可读取新版文字、原因及图片；观察账号访问新版详情和图片均为 404，匿名访问私有图片为 401，猜测新版公开图片路径为 404。
5. 公共列表仍为版本 1 的文字，余额保持 12 积分，没有第二笔奖励。请求按实际完整路径核验，未使用不存在的路径代替权限验证。
6. 发现灵感、我的投稿、后台审核列表分别检查 320、375、768、1280px，共 12 组，无文档横向溢出；另检查 320px 投稿表单和审核详情。修复新增页头入口在 320px 的溢出，并收紧投稿页顶部排列。

证据保存在忽略目录 `test/artifacts/inspiration-submissions-2026-10-25/`：

- `admin-reward-review.png`：审核奖励勾选、数量 12 与通过操作。
- `user-mobile.png`：手机个人投稿状态及操作。
- `layout-checks.json`：12 组实际视口宽度与文档宽度。
- `api-checks.json`：脱敏后的公开版本、余额、流水和图片权限状态码。
- `ai-request-counts.json`：隔离数据库的生图、反推及辅助调用均为 0。
