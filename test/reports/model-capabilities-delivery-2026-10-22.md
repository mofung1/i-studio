## 结果

- L02：公开模型返回参考图、比例和清晰度能力；通用、电商和服装表单过滤选项，保留不兼容配置与素材，明确提示并阻止提交，用户主动选择替代参数。
- L03：每张完成即保存和发布；运行中可以查看、下载已交付图片。持久化逐张阶段与供应商任务标识，复用已保存资产及已记录的加密来源；租约令牌阻止旧 Worker 迟到写入，按实际交付只结算一次。
- 当前三个配置协议均为同步服务；未收到并记下的结果无法查回，此时保留已有图片并退回剩余预留。原任务查询不重新提交生图，主动重新生成属于新任务并独立计费。远程查询恢复分支只通过显式支持的模拟 Provider 测试，本次没有增加真实异步适配器。

专项后端覆盖：

| 场景 | 核验内容 |
| --- | --- |
| 第一张完成、第二张正常失败 | 第二次请求前第一张已入库且任务 API 可见；图片内容接口可下载；未结束前删除返回 409；只收取实际交付积分 |
| 工作进程直接退出 | 独立测试子进程在第二次 Submit 内 `os.Exit(73)`；第一张已持久化。父进程使租约过期后恢复，第二张不重复提交，第一张保留、余额和退款正确 |
| 同步请求中断、旧 Worker 迟到 | 不重发原请求；旧令牌不能记录来源或完成结算；返回说明保留图片、退款及重新生成计费 |
| 已收到来源但尚未保存 | 来源以加密值持久化；恢复直接保存，不调用 Submit；公开任务不泄露供应商 ID 或加密来源 |
| 远程任务恢复能力判定 | 已记录任务 ID 且显式支持时仅 Poll；未声明支持时不 Poll、不 Submit，结束并释放剩余预留 |
| 图片数据库事务失败 | 强制约束失败后素材与任务进度一起回滚，不留下虚假交付或扣费 |
| 最后一张完成后、结算前退出 | 全部已保存结果直接结算，即使当前 Provider 不可用也不重复生成 |
| 八个 Worker 同时领取 | 只有有效令牌的 Worker 执行，单图请求总数等于任务张数，结算流水唯一 |
| 电商与服装部分恢复 | 图片位置、模块归属、生成文件名和实际收费一致 |
| 能力接口与升级 | 只公开模型能力，不泄露私有通道；旧库升级、重复迁移及新增字段/表通过验证 |

既有轮询截止时间、中途请求取消、协议错误、图片校验、权限、余额和幂等测试也随完整后端回归通过。供应商已完成但同步响应未到达本服务的情况，按结果不确定处理，不承诺远程找回。

专项前端覆盖：能力判断不修改原配置；旧能力响应兼容；显式替代参数按钮；电商/服装参数过滤；不兼容历史值可见；禁止新增不支持的图片并保留移除能力；有足够积分时仍拦截不兼容提交；生成中部分结果预览及新任务不混入旧结果；创建响应丢失后核对到已完成任务可恢复结果。

## 页面验收

使用独立 Next.js 生产构建和本机模拟 API、虚拟账户，在 1280×720 视口检查：

1. 默认受限模型保留原 `1:1 / 2K`，显示不兼容原因，上传禁用，生成按钮禁用；原因在固定底栏可见。
2. 点击“使用 3:4 · 1K”后恢复可提交状态，描述保留；比例下拉仅有 `3:4`。
3. 模拟生成 3 张时先显示“已保存 1/3 张”，可用图片预览与下载按钮；随后显示 3 张结果和完成状态。
4. 服装流程选择不支持参考图的模型时禁止上传并说明原因；切换到支持参考图模型后恢复上传，清晰度下拉只有 `1K / 2K`。

页面模拟结果使用仓库已有公开示例图，**截图不代表本轮真实 AI 生成或供应商能力验收**。没有上传用户私有图片，模拟服务不连接业务数据库；验收完成后关闭临时服务。
