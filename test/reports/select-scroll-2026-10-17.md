# 下拉列表滚动跳动修复（2026-10-17）

目标平台菜单在列表顶部仅显示向下箭头，中间同时显示两个箭头，底部仅显示向上箭头。原先箭头直接参与菜单布局，滚动时高度变化触发浮层重新定位：1280×720 下菜单顶部从 34px 变为 12px，上跳约 22px。

共享 Select 为两个滚动箭头保留固定位置，仅当列表需要滚动时占用空间。视口高度同时扣除两侧控制区与边框，短列表不预留控制区。保留 Radix 的滚轮、箭头自动滚动、键盘选择、弹窗内 Portal 与 Esc 焦点恢复机制；滚动边界限制在列表内部。
