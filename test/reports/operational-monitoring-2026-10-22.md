# L06 任务、预留与存储失败监控验收

日期：2026-10-22。按用户明确限定，仅实现任务积压、异常预留及存储失败监控；自动备份、恢复演练和物理磁盘容量监控不在本轮范围。

## 实现与范围

- 独立后台接口 `GET /v1/admin/monitoring`，使用 5 秒读取上限及只读、可重复读事务，提供快照时间、全量异常计数及最多 20 项定位记录。
- 生图和反推分别统计排队数量、最长等待、超过 5 分钟的排队和到期后再超过 60 秒的处理记录。
- 预留监控覆盖结束/缺失任务未结算、超过自身时间预算的预留和账户预留不一致；多图长任务按冻结超时与张数计算，0 积分任务不误报金额预留。
- 统一存储 Router 记录实际写入、打开、流读取/关闭、删除和签名失败；原存储结果保持不变，正常 EOF 不记失败，单个流重复错误只记录一次。数据库存固定分类、诊断编号和对象摘要；入库失败有脱敏日志及本进程漏记计数。
- 后台运营概览新增运行监控，每 30 秒在页面可见时刷新，支持手动刷新、回到页面更新和离开时取消请求。读取失败明确提示状态未知，旧数据注明为上次成功快照。
- 新增迁移 `015_operational_monitoring.sql`，失败事件保留 30 天；删除重试沿用既有机制。本轮没有迁移业务库、更新业务容器或调用付费 AI。

阈值、字段口径和运行边界详见 [功能说明](../../docs/operational-monitoring.md)。

## 浏览器验收

使用独立的 Next.js 生产构建、真实新版本 Go 监控接口、专用测试数据库与虚拟后台账号，视口 1280×720。仅注入合成异常；验收 API 没有配置 AI 通道，且不启动任务 Worker，以保留异常样本供检查。

1. 登录后显示三类异常、等待时长、快照时间与操作入口。
2. 展开定位记录可看到账户预留差额、异常任务编号、时长及金额；展开存储记录可看到本地/云存储类型、固定操作、摘要和诊断编号。
3. 定时刷新和手动刷新均更新快照；由于验收 Worker 关闭，样本租约自然到期后计数相应增加，属于合成场景。
4. 停止临时 API 后点击刷新，显示中文连接失败及“当前状态无法确认”，保留上次成功快照；恢复 API 并重新读取后正常显示数据。最终构建再次检查断连提示通过。

## 使用边界

当前提供后台页面中的状态与告警，不发送外部邮件、短信或消息。监控不会自动取消、重发、退款或修复账务。云存储签名跳转后的浏览器/CDN 下载失败无法直接观测；历史失败记录不等于当前仍失败。漏记计数只针对当前响应进程、重启清零。没有实施备份、恢复或物理磁盘容量监控，也未进行真实多副本部署验收。
