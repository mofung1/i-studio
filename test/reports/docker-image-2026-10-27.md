# 单应用镜像与 Compose 安装验收

日期：2026-10-27。应用镜像已发布到 [Docker Hub：mofugn1/istudio](https://hub.docker.com/r/mofugn1/istudio)。统一标签为 `latest` 和 `2026.10.27`，同时包含 Linux amd64 与 arm64。

统一清单摘要：`sha256:99b0f34795ead7eff1eb9c385601a2118a680a452b2aecf02b02ce09a56a1c7f`。

## 交付内容

单应用镜像包含 Next.js 前端、Go API、Caddy 同源访问入口，以及 798 条公共提示词、13 个分类和 797 张封面。Compose 使用官方 PostgreSQL 17 和 Redis 7 镜像，命名卷持久保存数据库、队列、用户文件及应用密钥；只发布应用的 8080 端口。

目标电脑可以直接从镜像导出 Compose 和随机初始配置，再启动安装，无需源码、Go、Node.js 或 Python。浏览器 API 使用同源 `/v1/`，不绑定构建电脑的 IP 或域名。配置与命令见 [Docker 镜像部署](../../docs/docker-image.md)。

原图片保持在 `server/storage/uploads/inspiration/`，没有迁移到新的种子图片目录。新增 `server/seed/inspiration-catalog.json` 仅保存公开提示词、分类、来源及图片字节校验清单；构建时直接读取原图片目录。镜像专属 Docker ignore 排除本机 `.env`、其他运行存储、测试产物和备份，不影响原开发 Dockerfile 的上下文规则。

首次启动在数据库事务和公共库锁内初始化，写入数据库初始化标记；已有公共库保持原样。重启、重建或更新镜像不会恢复管理员已删除的条目，也不会覆盖编辑及启用状态。进程管理器会在任一应用进程退出后终止其余进程，让 Docker 按重启策略恢复整个应用。
