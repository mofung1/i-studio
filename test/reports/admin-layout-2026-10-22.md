# 后台页面布局与间距整理

日期：2026-10-22。用户要求检查后台全部页面，统一间距和布局细节，沿用现有后台风格。

## 完成内容

- 用后台独立变量统一页面边距、卡片/弹窗内边距、区块间隔、字段间距和文本输入框高度；前台样式不受这些规则影响。
- 概览监控、统计、额度和准备事项之间统一留白，消除相邻卡片没有间隔的情况。
- 运营设置移除旧表单 margin 与 Field 组件 gap 叠加的空隙，注册开关集中排列，字段标签和提示上下对齐。
- 页标题与操作按钮去除额外顶部偏移；列表继续保留行距选择、固定列、分页及区域滚动。紧凑行距的单元格横向内边距与表头对齐。
- 模型测试比例、档位的标签改为上下排列，避免窄列换行挤到控件旁；渠道卡片补齐标题、输入和操作间隔。
- 存储配置去掉重复的「知道了」操作，取消/保存统一靠右；「可选」与字段名同行，密钥字段成对排列。
- 修复手机 AI 服务卡片操作按钮超出右边界的问题：原先纵向 flex 与换行组合使操作区进入横向新列，现改为正确的行布局换行。
- 手机灵感库整理为搜索、双筛选、操作三行，分页统一为三行布局，增加可查看列表的空间。
- 更新后台使用说明中已过时的「页面说明」描述，记录间距规范。

间距：桌面页面/面板 24px、主区块 24px、字段 20px、标签 8px；手机对应 16px、20px、16px、8px。文本输入框桌面 40px、手机 44px。运营设置大分组桌面 32px、手机 24px。
