# iStudio UI 设计交付规范

## 1. 设计方向

设计语言定义为“Monochrome AI Creative Workspace”。它是图片优先的专业创作工具，不是营销落地页，也不是传统 ERP/Admin Dashboard。页面以纯白、黑色和中性灰建立稳定层级，不使用界面主题色；商品素材与生成结果承担视觉色彩，状态通过图标、文案、明度和边框共同表达。

产品逻辑参考 PixPix 工作台的任务优先层级，但不复制其品牌视觉：模型是次级控制，创作任务和图片结果才是首要内容。

## 2. 页面框架

| 断点 | 导航 | 工作台 | 内容页 |
|---|---|---|---|
| `>= 1041px` | 64px 顶部导航 | 大画布 + 420px 配置面板 | 4 列工具/项目、3 列灵感 |
| `781~1040px` | 顶部导航 | 大画布 + 360px 配置面板 | 2 列工具/项目、2~3 列资产 |
| `521~780px` | 顶部导航 + 折叠菜单 | 画布/参数上下分区 | 2 列 |
| `<= 520px` | 58px 顶部导航 + 折叠菜单 | 单栏，生成栏吸底 | 工具/项目 1 列、灵感 2 列 |

## 3. 核心令牌

```css
--background: #ffffff;
--surface: #ffffff;
--surface-subtle: #f5f5f2;
--ink: #171717;
--muted: #737373;
--line: #e8e8e4;
--primary: #171717;
--primary-hover: #000000;
--primary-soft: #f1f1ef;
--success: #171717;
--success-soft: #f2f2ef;
--warning: #525252;
--danger: #171717;
--radius: 8px;
```

- 字体：Inter、Noto Sans SC、系统无衬线字体。
- 字号：10/11/12/13/14/16/18/20/29/42px。表单正文以 12~14px 为主，避免使用低于 10px 的可交互文字。
- 间距：4px 基准，主要使用 4/8/12/16/20/24/32px。
- 圆角：按钮 8px、输入 8~10px、图片 10~12px、任务和内容卡片 12~14px、核心 Composer 16px。
- 阴影只用于悬浮卡片、菜单、Toast 与核心结果，不用于普通页面分区。
- 色彩分配：导航、按钮、选中态、AI 状态和输入焦点仅使用黑白灰；图片自身承担内容色彩。

## 5. 关键组件状态

### Button

- 尺寸：默认 36px，核心生成按钮 42px，图标按钮 32px 正方形。
- 状态：default、hover、focus-visible、disabled、loading。
- 加载时保留原宽度，不造成布局跳动。

### Upload

- 支持 idle、drag-over、uploading、success、warning、error。
- 缩略图必须显示主图标识、删除操作和失败原因。
- 上传失败仅重试失败文件，不清空已成功文件。

### Generation Result

- 状态：empty、queued、analyzing、generating、success、partial-success、failed。
- 无真实进度时只展示阶段，不展示伪造百分比。
- 生成结果悬浮时出现预览与下载；移动端把操作放在卡片底部。

### Task Card

- 首页任务卡使用图片与简短任务文案，不展示后台式统计指标。
- Hover 时图片轻微放大，箭头由白底切为石墨底；键盘焦点需同样可见。
- Selected 仅用于电商工具标签、详情模块和电商视觉方向，不以大面积强调色填充。

### Unified Generation Workspace

- 通用生图与商品生图共用一个路由页面和大型白色应用窗口；旧版独立通用生图编辑器不再使用。桌面端四周保留 12px 呼吸空间，并以细边框、圆角和轻阴影建立弹窗感。
- 左侧一级菜单固定为“通用 / 商品”。选择“商品”后，顶部展示白底精修、商品场景图、卖点主图和详情页单页；选择“通用”后顶部只显示当前模式名称。
- 桌面端默认为左侧固定宽度配置面板、右侧结果画布；用户切换后两栏交换位置，配置内容始终独立滚动。
- 通用生图不展示商品任务标签、视觉拆解或自动质检信息条；结果画布使用纯白背景并尽量放大图片，配置区使用独立中性灰圆角面板。
- 配置面板位置属于工作区布局偏好，不属于生成参数。切换入口固定在“生成配置”标题栏右侧，使用左右面板图标分段控件；默认左侧，并在通用生图与商品生图间共享、持久化。
- 桌面端切换配置位置时只交换画布与配置面板，不改变参数顺序和任务状态；移动端隐藏该控件并固定为画布在上、配置在下。
- 模型选择和生成按钮固定在面板底部，不能随参数滚出视口。
- 详情页内容模块为单选；视觉拆解标签为多选，标签同时显示维度和值。

## 6. 可访问性

- 正文与背景满足 WCAG 2.2 AA。
- 所有纯图标按钮必须提供 `aria-label` 与 Tooltip。
- 状态不能只依赖颜色，必须配合文字或图标。
- 键盘焦点统一使用 3px 黑色半透明外环。
- 尊重 `prefers-reduced-motion`，扫描线与加载动画在减少动态模式下停止。
- 图片提供描述用途的替代文本，装饰图才使用空 `alt`。

## 7. 研发验收重点

1. 1280px 桌面首屏可看到任务首页核心创作框；编辑器可同时看到画布、独立滚动参数区和固定生成栏。
2. 最长平台名称、工具名称和中文文案不会撑破容器。
3. 首页输入框与顶部“AI 图片”进入统一工作台的“通用”；顶部“电商工具”及首页商品工具卡进入同一工作台的“商品”。
4. 两种模式共用统一模型列表，参数结构分别维护，默认数量均为 1。
5. 刷新页面后可从任务 ID 恢复生成状态。
6. 移动端不出现横向滚动，顶部折叠菜单与吸底生成按钮互不遮挡。
7. 空态、加载、局部失败和成功状态均有设计与实现。
8. 首页电商工具下方保留最近项目与发现灵感；顶部通知反馈固定显示在导航下方。
9. 桌面端配置面板默认左侧，通用生图与商品生图均可切换左右位置；刷新和跨模式后偏好保持，移动端不出现该切换控件。

## 8. 原型资产说明

原型使用 Unsplash 公共图片作为演示素材，仅用于内部 UI 评审。正式产品不得把这些图片作为系统模板或营销资产，应换成拥有明确使用权的商品素材。
