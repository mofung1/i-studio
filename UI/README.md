# iStudio UI 高保真原型

这是依据《AI 电商创作平台 PRD（MVP）》制作的前端设计基准。当前视觉采用黑、白与中性灰体系：导航和首页使用同一纯白背景，界面控件保持克制，让商品素材与生成结果成为主要色彩来源。原型优先表达布局、层级、组件状态和核心交互，不包含真实上传、鉴权、模型调用或计费逻辑。

## 当前演示范围

- 两种模式：通用生图与电商工具生图，共用统一模型路由，使用各自独立的参数结构。
- 通用生图：首页输入框进入统一生成工作台，通过左侧“通用”入口使用参考图、描述、风格、参考强度、比例、清晰度和数量。
- 电商任务：白底精修、商品场景图、卖点主图、详情页单页。
- 统一生成工作台：通用生图与商品生图共用弹窗式页面壳层，左侧一级菜单为“通用 / 商品”；大画布与独立圆角配置面板覆盖生成前、生成中、完成和失败状态。
- 详情页模块：首屏主视觉、核心卖点、使用场景、多角度、尺寸参数、材质成分与配件清单。
- 电商视觉方向：构图、色彩、材质、光影、风格、氛围六类可选标签，仅在电商模式出现。
- 创作积累：最近任务与项目卡片，用于恢复历史创作。
- 发现灵感：图片优先的案例浏览，并可带入通用生图。
- 资产中心：上传素材、生成结果和收藏的筛选与搜索。
- 首页内容：在电商工具下方保留最近项目和发现灵感列表，支持继续创作和浏览全部。
- 响应式：桌面采用固定编辑面板，移动端改为上下分区并保留吸底生成操作。

视频、穿戴和生成式快捷编辑不属于当前可演示原型，避免出现第三种生图模式或无行为入口。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 原型交互

- 顶部导航保持上一版的 `AI 图片 / 电商工具 / 发现灵感 / 项目 / 资产` 结构；`AI 图片` 与 `电商工具` 分别直接进入统一工作台中的“通用”和“商品”。
- 首页创作框默认执行通用生图；点击顶部“电商工具”直接进入默认电商生图工作台，首页工具卡进入对应电商任务；模型默认 `Auto · 推荐`。
- 画面设置菜单包含比例、清晰度和生成数量，两种模式均默认 1 张。
- 生成配置标题栏可切换面板在左侧或右侧；默认左侧，两种生图模式共用并在本机持久化该偏好，移动端固定使用上下布局。
- 点击电商工具进入聚焦编辑器；顶部任务标签支持快速切换。
- 详情页单页支持单选内容模块，并可逐项启停六个视觉拆解维度。
- 点击生成可体验需求理解、画面生成到结果完成的反馈链路。
- 完成态提供放大、裁剪和下载反馈。
- 项目可恢复最近创作；灵感案例可带入通用生图；资产支持分类与搜索。
- 顶部通知图标的反馈显示在导航下方，不遮挡页面底部操作。

## 正式开发映射

原型使用 React、TypeScript、Radix Tabs/DropdownMenu/Tooltip 与 Lucide。视觉组件按 shadcn/ui 的源码持有模式设计，正式开发时应使用 shadcn CLI 添加对应组件，并将本原型中的 CSS 变量迁移到 Tailwind 主题变量。

正式开发需替换的模拟部分：

- Unsplash 示例图替换为对象存储签名 URL。
- 本地页面状态替换为 Next.js App Router 和 TanStack Query。
- 模拟生成计时替换为任务 API 与 SSE 状态。
- 点数能力确认具体套餐和成本后，再接入服务端报价、冻结与结算结果。

详见 [DESIGN-SYSTEM.md](./DESIGN-SYSTEM.md)。
