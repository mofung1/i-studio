# iStudio UI-4

iStudio 的第 4 套前端视觉方案：**Studio Calm 生图工作台**。

## 设计定位

- 打开即进入生图工作台，不设置营销首页。
- 以暖白、雾灰和墨色为主体，使用克制的蓝色作为主操作色，辅以薄荷与蜜桃色表达状态；不使用无意义的小标题、编号和装饰性渐变。
- 左侧是任务配置（素材、生成描述、画面规格），右侧是画布与生成结果；画布使用一处缓慢、低对比的呼吸光效，上传、展开、选择和生成按钮提供短促反馈。
- 只设计并交付当前的「生图主页」；精修、素材库、灵感等入口保留为后续设计占位。

## 本地运行

```bash
cd UI-4
pnpm install
pnpm dev
```

默认端口：`3300`。

## 验证

```bash
pnpm typecheck
pnpm build
```
