# 对象存储与 CDN

后台入口为 `/admin/storage`。默认使用 uploads 本地持久卷，不填云存储密钥也能部署和生成图片。

## 添加云存储

支持阿里云 OSS、七牛云 Kodo、腾讯云 COS，以及 S3 / MinIO 等兼容存储。

1. 在供应商控制台创建私有桶，准备目标桶的访问密钥、区域、桶名及 Endpoint。
2. 在后台添加存储配置，按控制台填写参数。Kodo 使用其 S3 兼容空间与服务域名；COS 桶名包含 APPID。
3. 使用对象前缀时，将访问权限和配置限定到对应前缀。
4. 如果读写使用内网 Endpoint，另外填写同一个桶可供浏览器访问的外网下载 Endpoint。
5. 设置桶或 CDN 的 CORS，允许网站的精确来源执行 `GET`、`HEAD`。
6. 保存后设为默认，再用自己的图片验证上传、预览和下载。

MinIO 等服务如需路径风格地址，按供应商设置对应选项。密钥加密保存在数据库，界面不返回已有明文密钥。

## 默认存储与旧文件

切换默认配置只影响新文件，不会迁移旧图片。每个文件按原来的存储归属访问；旧桶、旧配置或本地卷仍需保留。

存储位置相关字段固定后，换桶、Endpoint、区域或目录时应新建配置；访问密钥、下载 Endpoint 和 CDN 可更新。云写入失败会返回错误，不会自动把失败图片保存到其他位置。

网站 Logo、签名及配置加密密钥仍保存在本地 uploads 卷。内置公共封面不会因为切换默认配置而自动上传到云端。

## 私有下载与 CDN

没有 CDN 时，图片接口校验账号归属，再提供临时签名下载链接。应用保存稳定的文件引用，不把会过期的签名 URL 当作数据库索引。

支持以下 CDN 下载鉴权：

| CDN        | 方式                        |
| ---------- | --------------------------- |
| 阿里云 CDN | 鉴权 A，参数 `auth_key`     |
| 腾讯云 CDN | 鉴权 A，参数 `sign`         |
| 七牛       | 私有下载凭证 `e` 与 `token` |

在云控制台设置与应用一致的签名密钥及 300 秒有效期，保持服务器时间同步。还需配置私有回源、CORS 和下载鉴权；缓存命中也应验证签名。仅将 CDN 域名指向私有桶，不能代替下载权限设置。

应用不会自动修改云平台权限或创建存储桶。云端读写、下载和流量按供应商规则收费。

## 备份与迁移

备份必须覆盖数据库、本地 uploads、安装配置和云桶。丢失 uploads 中的 `.ai/encryption.key` 或显式配置的加密密钥后，将无法解密原有 AI 与云存储密钥。

迁移历史图片时，需要复制并校验文件，再更新存储归属；切换默认配置不会执行这些操作。完整站点备份步骤见 [备份与恢复](operations.md#备份)。
