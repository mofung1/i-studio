# 对象存储与 CDN

后台入口为 `/admin/storage`。公共提示词库封面、用户上传、AI 生成图片、网站 Logo 和图片附件共用这里的一套配置。未启用 OSS 时从本地 `uploads` 读取；启用后，新图片同时写入本地和 OSS，浏览器通过配置的 CDN 或对象存储下载。

## 目录和访问地址

文件引用保存相对于 `uploads` 的路径，不写死平台、Bucket 或 CDN 域名，例如：

```text
uploads/
├── image/          AI 生成图片，按日期组织
├── user/           用户上传、反馈和投稿原图
├── inspiration/    内置封面和审核通过的投稿封面
├── .reverse/       保留期内的图片分析素材
└── .site/          网站 Logo 和联系二维码等图片
```

本地卷的实际位置以部署挂载为准。容器中通常为 `/data/uploads`；宝塔五容器示例的宿主机路径为 `/www/istudio/docker/data/uploads`。

内置公共库封面统一使用 `inspiration/library/<内容SHA-256>.<扩展名>`。电脑开发目录、服务器运行卷、数据库引用和七牛对象均保留 library 层。目录中相同内容按哈希去重；来源记录仍保留原文件名用于追溯。历史平铺目录可用 `scripts/normalize-inspiration-paths.py` 在备份后迁移，旧读取地址仍兼容。迁移线上站点时，“本地 uploads”指服务器正在使用的卷，各环境的条目数量可能不同，应复制目标数据库对应的实际运行目录。

若后台对象目录前缀为 `uploads`，本地 `inspiration/library/<sha256>.jpg` 对应对象键 `uploads/inspiration/library/<sha256>.jpg`。CDN 域名只填写 `https://img.example.com`，不附加目录。前缀为空时，业务目录直接位于桶根目录。

读取公共封面时，应用允许游客获取访问地址；读取用户作品前校验账号归属。公开模式使用无签名直链；私有模式的签名 URL 会过期，不作为永久文件引用。浏览器也可能将图片显示为 `blob:`，它只是页面创建的临时预览地址，不是云端文件路径。

## 后台配置

支持阿里云 OSS、七牛云 Kodo、腾讯云 COS、S3 / MinIO。

1. 在云平台创建空间，取得区域、空间名、Endpoint 和访问密钥。公开直链要求空间读权限为“公共读、私有写”；若空间保持私有，必须配置 CDN 域名并选用对应的下载鉴权，否则图片无法直接打开。
2. 如需 CDN，绑定指向该空间的 HTTPS 域名，配置证书和 DNS；公开直链无需下载签名，私有访问才配置相应回源和下载鉴权。
3. 在后台勾选“启用 OSS 云存储”，填写同一套存储与 CDN 参数。
4. 先把本地业务图片按原目录结构上传到目标空间。可使用供应商工具手动上传，也可以点击“同步本地图片”；同步按批次执行，不改变本地文件和数据库引用。全新安装时提示词库封面只在容器首次启动写入本地 `uploads/inspiration`，启用云存储后必须执行一次同步，否则封面在云端 404。
5. 下载鉴权选择“公开直链”时，点击“检查连接”验证 OSS 读写和无签名 CDN 下载。选择私有下载时，额外检查无签名和过期签名被拒绝。
6. 保存配置。公共封面、历史图片和新图片立即按该配置访问，无需重启服务。

连接检查只创建并清理应用自己的临时测试对象。同步只传输图片文件，不传输 `.ai` 配置目录、JSON 配置、私钥或数据库备份。同步期间请保留当前页面；失败可重试。首次切换时应在低访问量时完成上传，并复核同步期间新增的文件。

首次迁移建议直接用后台的“同步本地图片”：对象由应用写入，会带上正确的 `Cache-Control`。使用供应商工具批量上传时，也应设置缓存头，或在 CDN 上按目录（`/uploads/inspiration/`、`/uploads/image/`、`/uploads/user/`）设置缓存规则。不要上传 `.ai/`、`.auth/` 内的密钥和配置；`.reverse/` 是有保留期限的分析图片，应用按图片处理，同步不包含其中的非图片文件。

密钥加密保存在数据库，不返回已有明文。留空保留已保存密钥；更换平台或存储 Endpoint 时需重新填写。云写入失败会明确返回错误，不会把仅保存在本地的图片冒充为云上传成功。

## CDN 访问方式

公开空间配合“公开直链”时，所有业务图片均返回稳定的无签名地址，持有链接即可查看，不依赖登录。应用页面和管理接口仍保留账号权限校验。本版本采用这一模式。

公开直链的缓存行为由应用写入对象时决定，不需要在 CDN 控制台逐条配置：

| 目录 | 对象缓存头 | 说明 |
| --- | --- | --- |
| `inspiration/` | `public, max-age=2592000, immutable` | 内置封面与投稿封面，键不变即内容不变，缓存 30 天 |
| `image/`、`user/` | `public, max-age=86400` | 生成图和上传图，缓存 1 天以便删除尽快生效 |
| 其他（`.site/` 等） | `public, max-age=86400` | 每次更新都会换新键 |

CDN 应设置为遵循源站缓存头。本次七牛域名原先采用“自定义·全局 30 天”，应改成“遵循源站”，或按目录单独配置（`/uploads/inspiration` 30 天、`/uploads/image` 与 `/uploads/user` 1 天），否则删除的图片可能在边缘留存一个月。

应用把 `/v1/assets/{id}/content`、`/v1/assets/{id}/thumbnail`、`/v1/inspiration/images/{key}` 以 302 跳到公开地址，302 本身缓存 10 分钟：同一张图在短时间内重复加载不会再请求应用接口，切换平台或 CDN 域名也能在 10 分钟内自动收敛。列表接口对公开封面直接返回绝对地址，不产生 302。

代价是**图片地址即权限**：用户作品、上传原图和封面共用同一套公开地址，任何拿到链接的人都能访问和转存，因此不要用它存放合同、身份证件等私密素材。删除图片时应用会同时删除对象，但边缘节点已缓存的副本会保留至缓存过期：用户图片为 1 天，公共封面为 30 天。需要立即下线时在 CDN 控制台提交刷新。浏览器与 CDN 的 CORS 需允许本站来源执行 `GET`、`HEAD`，否则画布导出等前端读取会失败。

私有空间是可选方案：应用为允许访问的资源生成临时链接，CDN 在缓存命中时也应校验签名。目录分类不能代替访问权限控制。

| CDN | 应用支持的鉴权方式 |
| --- | --- |
| 公开直链 | 所有平台可用；使用公开空间和无签名 CDN URL |
| 阿里云 CDN | 鉴权 A，参数 `auth_key`，云端有效期 300 秒 |
| 腾讯云 CDN | 鉴权 A，参数 `sign`，云端有效期 300 秒 |
| 七牛 | 私有下载凭证，参数 `e`、`token` |

读写使用内网 Endpoint 时，填写同一个桶的公网下载 Endpoint。桶或 CDN 的 CORS 应允许本站来源执行 `GET`、`HEAD`。只配置 CDN 域名不会自动创建云服务或设置云端权限。七牛接入步骤见[七牛配置手册](qiniu-oss-cdn.md)。

## 更换 OSS 或 CDN

1. 备份数据库及本地 `uploads` 卷，保留当前平台配置用于回退。
2. 将 `uploads` 内的业务图片目录按原结构复制到新空间的指定前缀。校验文件数、字节数及关键图片校验值。
3. 在新平台配置好 CDN、HTTPS、DNS，以及所选访问模式对应的规则。
4. 在同一个后台表单修改平台、空间、区域、Endpoint、目录前缀及密钥；填写新的 CDN 域名。
5. 检查连接后保存，检查公共封面、用户图片、缩略图、下载和新上传；历史图片统一使用新配置。

无需逐条改图片地址或修改数据库存储归属。旧版本的 `@storage/<配置ID>/...` 文件引用会兼容解析为相对路径；如旧版曾只在云端保存文件，先从原云空间补齐本地对应目录，确保回退与以后搬迁时文件完整。

本版本不再读取单独的公共封面 `CDN_BASE_URL`。旧部署升级后应删除该变量，并在后台配置统一存储。

关闭“启用 OSS 云存储”并保存即可切回本地；因为本地保留完整副本，不需要修改图片记录。云端文件和旧平台不会自动删除，确认迁移完成后由维护者处理。

## 备份

`uploads` 同时包含业务图片和本地密钥、配置文件。整卷备份应保密；向对象存储搬图片时仅上传业务图片，不上传 `.ai/encryption.key`、`.site/config.json` 等配置。数据库与加密密钥需一起备份，否则无法解密后台保存的访问密钥。完整步骤见[备份与恢复](operations.md#备份)。
