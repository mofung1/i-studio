# 资产管理

在“我的资产”中分别浏览生成作品、我的素材和创作记录。所有查询、缩略图、元数据修改与下载均按当前账号校验；需要 PostgreSQL。

点击通用参考图、电商商品图、服装原图、模特图和场景图的原上传区域，统一打开素材选择器；已选图片的“添加”和“替换”也使用同一入口。弹窗内支持本地选图、拖入文件，以及素材/生成作品切换、搜索、项目、收藏筛选与分页。本地图和库内图片可以按选择顺序混选，数量共用当前位置的剩余额度；确认前不改动当前配置，关闭即取消。主页面也保留直接拖入图片。

素材选择器使用完整比例预览，不裁切、不压缩图片格；点击放大按钮可查看原图。本地图选择后立即显示在上传入口下方的“待使用的图片”区域，并滚动到预览位置；点击“使用所选素材”才带入当前创作。标题和确认操作固定，列表独立滚动，小屏显示两列。本地选图限制 JPG / PNG / WebP、单张 10 MB，提交生成时仍校验总大小和像素上限。已有图片直接提交资产 ID；历史恢复与“用作参考图”只读取元数据，不再下载后重新上传。同一账号内容相同的本地上传复用记录，不跨账号去重。

未登录时仍可选择本地图片；素材库显示登录入口，不请求私有列表。资产页、个人提示词和个人中心统一显示登录提示，登录后返回原页面；登录状态确认期间不显示私有操作。退出登录或切换账号时，清除原账号的私有列表、待选素材和当前生成结果。

生成中的素材不可删除。删除被历史任务引用的图片时，图片从资产列表和任务结果移除，原文件保留供历史配置恢复；当隐藏超过 7 天且没有任务引用时，后台清理原文件与缩略图。可见素材不会因闲置而自动删除。云端删除失败使用持久化重试队列。

- 名称、原提示词和标签搜索；工具、模型、日期、标签与收藏筛选。
- 最新 / 最早排序；“加载更多”读取下一页数据库记录，支持超过 200 条历史。相同创建时间使用记录 ID 保持稳定顺序。工作台历史抽屉也可继续分页。
- 图片独立命名、收藏与最多 12 个标签。整理弹窗可指定项目。
- 项目可新增、改名、归档、恢复和移除。归档项目继续可查看，不能作为新增移动目标。移除项目保留图片与记录，解除所属项目。
- 选择图片后可批量收藏、移动或打包下载。每次最多 100 张，ZIP 总源文件体积最多 250 MB。批量修改整体校验归属，一张无权访问则整批不修改。
- 项目内的“在项目中创作”会把新任务与生成图片归入该项目。图片可单独移动，同一任务的图片允许分属多个项目；按项目查看创作记录时包含所属图片的任务。
- 预览支持查看原图、编辑信息、图片反推、用作参考、回填历史配置。继续创作只载入配置，不自动调用生图接口。

资产页默认紧凑排列，可切换舒适视图。列表缩略图按最长边 480px 等比缩小，原图保留；生成后缓存至原图所属存储，后续复用。

缩略图支持最高 1 亿像素，同时受解码内存预算约束：全局预估预算为 768 MiB，并发最多 2 个生成请求。渐进式 JPEG 会将额外的解码系数缓冲计入预算；大图先缩小到中间尺寸，再进行最终高质量缩放，避免缩放缓冲随原图高度增长。大图处理后回收解码缓冲，再放行等待的请求。超过像素或解码内存上限会明确返回预览错误，原图仍可下载。

浏览器图片缓存同时限制 120 张与 96 MB 的 Blob 体积；图片解码后的内存另由浏览器管理。云存储和 CDN 配置见 [对象存储说明](object-storage.md)。

## 文件目录

本地默认根目录为 `server/storage/uploads/`，用户上传与生成作品按北京时间的年月日分别保存：

```text
uploads/
  user/20260919/<资产 ID>.png          # 用户上传素材
  image/20260919/<资产 ID>.png         # AI 生成作品
  inspiration/                       # 公共灵感封面
```

文件扩展名保留实际图片格式；缩略图与原图同目录，文件名为 `<原图文件名>.thumbnail-v1.jpg`。新文件按保存时的北京时间分目录；同账号重复上传仍复用已有素材，不重复建文件。

2026-10-25 已将当前本地历史资产按原记录的北京时间创建日期迁入上述目录，并同步更新原图与缩略图索引。资产 ID、访问接口、所属账号和历史任务引用保持一致，读取仍兼容数据库内保留的旧路径。迁移记录及备份位置见 验收报告（历史记录，可从 Git 历史查看）。

## 接口

- `GET /v1/library/assets`：kind、q、projectId、favorite、tag、taskType、model、from、to、sort、limit、cursor；返回 assets、total、nextCursor。
- `PATCH /v1/library/assets`：ids 与 title / tags / favorite / projectId。空 projectId 表示移到未分类。
- `POST /v1/library/download`：ids，返回 ZIP。
- `GET /v1/assets/{id}/thumbnail`：账号私有 JPEG 缩略图。
- `GET /v1/assets/{id}/metadata`：账号私有素材元数据，用于选择和恢复配置。
- `POST /v1/projects`、`PATCH /v1/projects/{id}`、`DELETE /v1/projects/{id}`：创建、改名/归档、解除项目归属。
- `GET /v1/generation/tasks`：保持原 tasks 响应，增加稳定分页、total 与 nextCursor。

数据库迁移只新增元数据列与索引，现有图片和生成参数保留。验证包括 207 条同时间记录的完整分页、跨账号访问、批量修改回滚、项目解除、缩略图尺寸和私有 ZIP 下载；不调用真实 AI。
