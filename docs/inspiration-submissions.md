# 用户提示词投稿与审核奖励

前台入口：发现灵感顶部的「分享提示词」「我的投稿」；个人提示词卡片也可「提交分享」。后台入口：**AI 与内容 → 用户投稿审核**（`/admin/submissions`）。

## 投稿流程

登录用户填写标题、现有公共分类和提示词，选择自己素材库或生成作品中的图片作为效果封面，也可通过素材选择器上传。使用说明、需要参考图为选填项。提交前需明确确认有权分享文字和图片，并同意通过后公开、供其他用户复制使用。

在「我的提示词」点击「提交分享」，直接在当前页面打开弹窗，自动带入该卡片的标题、完整提示词（包括换行和变量）及匹配的公共分类。分类没有匹配时手动选择；封面和公开确认仍由用户补充。提交后留在原列表并显示「查看我的投稿」入口。

个人提示词保存和编辑继续默认私有，提交只复制当次内容。每条个人提示词对应一条投稿，重复点击或网络重试复用提交编号；同账号已提交的同段文字会提示回到原投稿修改。待审核的提示词再次点击时显示审核状态，避免重复提交；退回后重提优先载入当前私有文字，保留原封面及退回原因。跨账号内容是否值得收录仍由管理员审核。

旧的 `?from=个人提示词编号` 链接仍兼容，读取个人详情的 `{ item }` 返回结构，加载成功后移除来源参数；不把完整提示词放进 URL。投稿与审核弹窗的正文独立滚动，底部操作统一靠右，提交或通过按钮排在最后。分享表单的关闭图标、取消和 Escape 直接关闭，不弹放弃修改确认。

| 状态 | 本人 | 其他用户与访客 | 管理员 |
| --- | --- | --- | --- |
| 待审核 | 查看、撤回 | 不可见 | 查看、通过或退回 |
| 未通过 | 查看原因、修改重提 | 不可见 | 查看记录 |
| 已通过并上架 | 查看、修改重提、撤回 | 查看、复制、收藏到个人库、去生图 | 查看、下架 |
| 已撤回或下架 | 保留记录，可重新提交审核 | 不再展示 | 保留记录 |

提交后内容固定为独立版本；待审核时先撤回才能修改。编辑已通过的投稿会创建待审核新版，已通过旧版继续公开，直到新版通过或撤回分享。新版被退回时，只有新版保持私有，旧版继续按原审核结果展示。

「我的投稿」与公共列表分开查询。标题、正文、封面、版本和退回原因均由后端检查账号归属；前台会话和后台会话分别验证，管理员只能通过投稿接口读取提交的封面，不能因此访问该账号的其他素材。

## 管理员审核与积分

审核详情同时显示封面、提示词、使用说明、分类和版本记录。通过前可调整到现有分类；退回必须填写原因。公共灵感库中的用户投稿只能跳转回审核入口处理，不能绕过版本审核直接修改正文。

- 「审核通过时奖励积分」默认不勾选；不勾选则正常发布，不发积分。
- 勾选后填写 **1–1,000,000 的整数数量**。界面使用后台配置的积分名称；API 与数据库仍按 100 个最小单位等于 1 积分保存。
- 通过、发布、奖励入账、积分流水和审核日志在同一数据库事务中提交。积分、存储额度或存储写入失败时，保持待审核，不产生部分发布或部分奖励。
- 每条投稿最多获得一次奖励。发布新版、撤回、下架后重新提交均不会重复奖励；此前没有奖励的投稿，之后的待审核版本仍可由管理员选择奖励。
- 同一审核请求重试返回已处理结果，不再次发奖；版本已更新或另一审核决定已生效时，要求刷新。
- 奖励流水类型为 `inspiration_reward`，个人中心显示「投稿奖励」，记录投稿标题与操作管理员。用户在「我的投稿」也可看到累计奖励。
- 撤回和下架保留已发积分及审核记录，不自动追回。奖励由人工决定，未新增自动奖励、签到规则、在线支付或供应商费用。

## 开关、次数与图片

后台审核页支持投稿开关和每人每日提交上限，默认**开放、每天 5 次**，可设置 1–100 次。新建和修改重提共用北京时间自然日额度，撤回不会返还次数；重复请求不重复计次。关闭后已有记录可查看、审核和撤回。

封面在提交时生成最长边不超过 1280px 的 JPEG，去除源文件元数据，原素材不修改。私有快照使用 `user/YYYYMMDD/submissions/`；通过后独立公开副本使用 `inspiration/community/`。两者均沿用所选本地或云存储配置，计入账号存储额度。

社区封面必须与已上架公共记录匹配才可通过图片接口读取，不直接走匿名 CDN 地址或长期公共缓存。未通过的版本不复制到公开目录；下架后新的公开请求返回 404。已经下载或保存的副本无法由网站收回。

版本记录按 20 条分页，封面展开时才加载。投稿内容以纯文本渲染，个人投稿页保持 noindex；原有公共灵感页的收录策略不变。

## 接口与部署

| 接口 | 用途 |
| --- | --- |
| `GET /v1/inspiration/submission-settings` | 公开投稿开关、每日上限和可选分类，不包含私人投稿数据 |
| `GET/POST /v1/personal/inspiration-submissions` | 本人列表、提交；可用 `personalPromptId` 按来源筛选，仍强制限制当前账号 |
| `GET/PUT /v1/personal/inspiration-submissions/{id}` | 本人详情、版本分页、修改重提 |
| `GET /v1/personal/inspiration-submissions/{id}/cover?version=N` | 本人指定版本封面 |
| `POST /v1/personal/inspiration-submissions/{id}/withdraw` | 本人撤回 |
| `GET/PUT /v1/admin/inspiration-submission-settings` | 管理员读取、修改投稿设置 |
| `GET /v1/admin/inspiration-submissions` | 按状态、标题、编号、用户名筛选，分页 |
| `GET /v1/admin/inspiration-submissions/{id}` | 审核详情与版本记录 |
| `GET /v1/admin/inspiration-submissions/{id}/cover?version=N` | 管理员读取指定投稿封面 |
| `POST /v1/admin/inspiration-submissions/{id}/review` | 通过或退回，可选积分奖励 |
| `POST /v1/admin/inspiration-submissions/{id}/unpublish` | 管理员下架，需填写原因并记录操作日志 |

新增迁移 `019_inspiration_submissions.sql`，随 API 启动执行。本机 API 和前端已于 2026-10-25 更新，正式部署时同样需要更新两者。验收与备份见 [专项报告](../test/reports/inspiration-submissions-2026-10-25.md)。
