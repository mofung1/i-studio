# 首次配置

完成部署并以管理员登录 `/admin/login` 后，按以下顺序配置站点。所有供应商账号、API Key 和模型访问权限由部署者自行准备。

## 1. 添加生图渠道

进入后台 **AI 服务**：

1. 添加生图渠道，选择与供应商匹配的协议。
2. 填写服务名称、Base URL、API Key 和超时，启用并保存。
3. 渠道页的测试模型 ID 仅用于测试；正式任务的模型 ID 在下一步的模型绑定中设置。

| 协议            | 适用接口                                   |
| --------------- | ------------------------------------------ |
| `openai_images` | 兼容 Images generations / edits 的图片服务 |
| `openai_chat`   | 使用 Chat 多模态消息返回图片的兼容服务     |
| `gemini_native` | 兼容 Gemini 原生 generateContent 的服务    |

Base URL 填服务根地址，例如供应商文档中的 `https://api.provider.example/v1`，不要重复追加完整 `/images/generations`、`/chat/completions` 或模型调用路径。协议以供应商提供的接口为准，不能只根据模型显示名判断。

渠道地址应是可访问的公网 HTTP(S) 服务；localhost、内网地址以及带账号密码、查询或片段的 URL 会被拒绝。真实生图测试可能产生供应商费用，按页面显示确认后再执行。

## 2. 添加前台模型

进入 **模型与定价**：

1. 新建模型，填写前台显示名称和每张图片的积分价格。
2. 在“渠道与主渠道”中绑定刚保存的生图渠道，填写该渠道实际使用的上游模型 ID。
3. 选择主渠道，并按真实支持情况设置比例、分辨率和参考图能力。
4. 开启“上架到前台”，保存模型。

用户只能选择已上架且有有效主渠道的模型。仅添加渠道不会自动得到一个可用的前台模型。免费模型需明确将价格设为 0；价格单位是站内积分。

同一公开模型可绑定多个渠道，但备用渠道不会自动接管任务。切换主渠道需要保存模型，新任务使用新的绑定；已创建任务保留原配置。

## 3. 配置提示词服务

按需添加 Prompt AI，用于 AI 优化、图片反推和服装规划。图片反推或识图需要服务支持图片输入，并在配置中启用对应能力。未配置时仍可手工填写生图描述。

后台“系统提示词”可维护各功能的共享模板。修改供应商配置后无需重新构建镜像。

## 4. 设置注册与积分

进入 **运营设置**，配置是否开放注册、邀请码、注册赠送及预算、每日签到奖励、单用户并发和存储额度。页面可用选项以站点当前版本为准。

再进入前台 `/login`，点击“没有账号？创建账号”注册普通用户。可以通过注册赠送、签到奖励，或由管理员在“用户与余额”中为指定用户增加积分。后台调账需要填写原因。

生图前显示预计积分，提交时预留，按实际保存的图片张数结算；未交付部分退回。站内积分不等同于供应商实际账单，当前不提供在线支付充值。

## 5. 网站与存储

- **网站配置**：修改名称、Logo 和联系方式；网站公告在“运营设置”中维护。
- **公共灵感库 / 用户投稿审核**：维护公开提示词、分类与投稿奖励。
- **对象存储**：默认使用本地持久卷，不配置云存储也能使用。多云设置见 [对象存储与 CDN](object-storage.md)。
- **域名与收录**：公网 HTTPS 和搜索收录设置见 [域名与 SEO](seo.md)。

全部完成后，用普通用户提交一张图片验证服务、积分和存储。该步骤会按模型配置产生站内扣费，也可能产生供应商费用。
