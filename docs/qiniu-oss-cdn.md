# 七牛云 OSS / CDN 配置手册

七牛的对象存储产品叫 Kodo。本项目在后台“图片存储”维护一套连接，公共提示词库、用户上传和生成图片共用空间、目录前缀和 CDN 域名。文件组织及换平台步骤见[对象存储与 CDN](object-storage.md)。

## 1. 准备空间和访问参数

本次采用标准存储的**公开空间**，后台下载鉴权选择“公开直链”。使用七牛控制台空间概览给出的 S3 空间名、区域和访问域名。以华南为例：

| 后台字段 | 示例 |
| --- | --- |
| 存储平台 | 七牛云 Kodo |
| 区域 | `cn-south-1` |
| 存储 Endpoint | `https://s3.cn-south-1.qiniucs.com` |
| 空间名 | 空间概览中的 S3 空间名，可能与普通空间名不同 |
| 外网下载 Endpoint | 使用公网 Endpoint 时可留空 |
| 目录前缀 | 如 `uploads` 或 `istudio`，不含头尾斜线 |
| S3 路径风格 | 按供应商要求；七牛支持路径和虚拟主机风格 |
| Access Key / Secret Key | 有权读写该空间的访问密钥，直接填写后台 |
| CDN 域名 | 公开直链必填，如 `https://img.example.com` |

不要将 Kodo 区域简称 `z2` 填作 S3 区域。访问密钥不写入前端代码、公开仓库或配置文档。

> **CDN 域名在七牛是必填项**：七牛的 S3 服务域名（`s3.<区域>.qiniucs.com`）不支持匿名访问，即使空间是公开的，请求也必须携带签名。选择“公开直链”却不填 CDN 域名时，后台会直接拒绝保存并提示，而不是等到图片打不开才暴露。

## 2. 配置 HTTPS CDN 域名

1. 绑定自定义加速域名，例如 `img.example.com`，源站选择同一个空间。
2. 国内加速按七牛要求完成实名认证和域名备案。
3. 绑定覆盖该图片域名的受信任 HTTPS 证书，可开启强制 HTTPS、HTTP/2。
4. 按控制台要求完成域名所有权验证；DNS TXT 验证记录与 CDN CNAME 分别配置。
5. 在 DNS 服务商处添加七牛实际分配的 CNAME，不能填写源服务器 IP。
6. 公开直链模式不启用私有下载鉴权；文件更新使用新名称或哈希。若另行选择私有空间，则需开启对应回源鉴权并验证签名过期行为。
7. 配置缓存：七牛默认是“自定义·全局 30 天”，与本站按目录区分的缓存头不一致。改成“遵循源站”，或按目录配置 `/uploads/inspiration` 30 天、`/uploads/image` 与 `/uploads/user` 1 天，否则用户删除图片后边缘节点仍会保留一个月。
8. 配置允许本站来源执行 `GET`、`HEAD` 的 CORS。

公开模式下通过后台“检查连接”验证上传、读取和无签名 CDN 访问。私有模式的无签名、过期签名请求应被拒绝；公开模式允许凭链接访问。

## 3. 申请或上传证书

证书必须覆盖图片域名。只有 `studio.example.com` 的证书不能用于 `img.example.com`；包含后者的证书或合适的泛域名证书可以使用。

个人用户可以在宝塔创建独立图片域名站点，申请 Let's Encrypt 证书。选择 DNS 验证后，在 DNS 平台添加当次生成的 `_acme-challenge` TXT，等待验证与签发。在七牛“证书管理 → 上传自有证书”填写完整 PEM 证书链与匹配的私钥，再绑定到 CDN。

图片域名已经 CNAME 到七牛后，继续使用 DNS 验证续签。手动上传的证书不会自动跨平台更新；续签后需要在七牛更换并部署，按实际到期日提前安排。私钥只保存在受信任服务，不写入文档。

## 4. 上传图片并保存后台配置

将本地 `uploads` 内的业务图片按原结构放到云端前缀下。例如前缀为 `istudio` 时：

```text
本地：uploads/inspiration/library/example.jpg
云端：istudio/inspiration/library/example.jpg
CDN：https://img.example.com
```

不要额外套一层重复的 `uploads`，也不要上传整个 ZIP 后认为云端会自动解压。图片可手动上传，也可在后台使用“同步本地图片”。

在后台填写前述空间参数、CDN 域名及“公开直链”，检查连接后保存。目录前缀单独填写，CDN 字段不包含路径。配置一次即可用于各类图片；不再配置公共库专用环境变量。

## 5. 验收和回退

- 公共提示词库返回同一 CDN 的无签名直链，封面正常显示。
- 上传一张自己的图片，确认本地与云端均存在，预览和下载成功。
- 应用管理接口继续校验账号；公开图片直链可由持有者直接查看。
- 公开直链无需签名即可成功访问，重复请求可命中 CDN 缓存。
- 更换域名只改后台配置；切回本地后已有图片仍可访问。

数据库保存相对文件路径，访问时按后台当前配置生成完整 CDN 地址。更新图片优先使用新文件名；迁移后清理旧 CDN 缓存时，注意云平台刷新不会清除用户浏览器已经保存的缓存。
