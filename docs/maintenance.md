## 查找与恢复

归档根目录的 `cleanup-manifest.json` 记录原路径、文件数、字节数和清理前 Git 版本。归档根目录限制为当前用户访问，备份等私有文件沿用其原权限。

恢复单个本机文件时，按清单原路径从归档复制到工作区。为避免覆盖后续修改，先比较目标文件；不要将整个归档或数据库备份重新加入 Git。

已提交文件也可从清理前版本提取，例如：

```sh
git show 0642ae8:TODO.md > /tmp/istudio-TODO-before-cleanup.md
```

该命令只写出一份历史文件用于查看，不修改当前源码和运行数据。归档是本机副本，不随其他电脑克隆；常规部署备份仍应按 [Docker 部署说明](docker-image.md) 执行。
