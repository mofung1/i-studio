# 创作素材与图片查看

## 素材选择

`AssetPicker` 使用固定高度的弹窗。顶部将本地添加入口与已选图片合并为单行：左侧固定添加卡片，右侧为独立横向滚动的已选图片。桌面卡片为 96×96 px，手机为 80×80 px，横图、竖图和长图均在固定画框内完整显示。中央素材区独立纵向滚动，底部只保留选择数量、清空和确认操作。

横向溢出时显示方向箭头和边缘渐隐，支持触控板、手指及左右键浏览。新增图片仅将已选栏滚到新图片，不滚动弹窗或素材库；移除图片保留浏览位置（末端空间变小时由浏览器正常收回）。窗口尺寸和图片数量变化会更新箭头可用状态，用户启用减少动态效果时不使用平滑翻页。

已选图片可放大预览、移除和清空，点击确认才交给创作配置。本地文件不会因暂存或预览而上传；外部参考图的多图折叠、展开和排序保持原有交互。

筛选区按「搜索 → 素材来源 → 收藏 → 项目」排列。桌面使用单行 40 px 高度的控件；来源为原生单选框组成的分段选择器，支持方向键切换。收藏是独立筛选，可与来源、搜索和项目叠加。窄屏来源自动切换为下拉框，手机搜索独占一行，其余三个筛选位于下一行，触控高度为 44 px。切换筛选不清空已选素材。

素材网格以 160 px 为最小卡片宽度自动排列，1000 px 宽弹窗下为五列，卡片宽约 184 px、间距 10 px；手机保留两列。相较原来的独立来源栏，桌面筛选区节省约 48 px 高度，图片仍采用 contain 完整显示，名称、尺寸和预览操作保持可读。


## AI 优化

排查并修复了这些失败路径：

- 通用提示词输入允许 10000 字，优化接口原先只允许 2000 字；现在统一为 10000 个 Unicode 字符，编辑器超限时先提示。
- 纯文本请求使用字符串 content，有参考图时才使用多模态内容数组；响应兼容字符串和 text 内容块。
- 优化输出预算由 800 调整到 4096 tokens。DeepSeek 优化请求使用 `thinking.type=disabled`，避免默认思考模式消耗用于简短改写的预算。[DeepSeek 思考模式说明](https://api-docs.deepseek.com/guides/thinking_mode/)
- `finish_reason=length` 被识别为未完成输出，不会把截断的结果覆盖到原文。
- 超时、限流、供应商授权失败、接口配置错误、内容过滤和响应格式异常分别提示。服务端日志记录错误类别和模型，不将原始供应商报错或密钥展示给用户。
- 本地参考图压缩后仍超过 5 MB 时，在请求前解释原因；网络错误和空结果也有明确提示。失败保留原文，支持重试和成功后撤销。

没有为失败自动重复调用供应商。验证使用模拟 HTTP 服务和模拟客户端，未使用实际供应商密钥或产生付费 AI 请求；线上额度、鉴权和模型能力仍由实际配置决定。

## 图片查看

通用生图及全部电商工具（含服装组图）共享 `ResultWorkspace`、`ImageViewport` 和 `ImageLightbox`。新结果和历史结果都采用相同的完整图片适配逻辑；主图两侧为上一张/下一张，计数、原图下载、全屏、继续创作及对比放在顶部工具栏。服装图组打包下载保留在顶部。

多图缩略图栏不再因查看来源改变显示规则，最近生成统一为可展开的横向版本栏，默认收起。查看历史时保留当前会话的版本入口，切回某版本会落在指定图片上。全屏查看也采用两侧切换与顶部下载、缩放和裁剪操作；切图会复位缩放和裁剪。
