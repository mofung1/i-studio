# 用户使用指南

先由站点管理员完成 [AI 与模型配置](configuration.md)，再到前台 `/login` 登录，或点击“没有账号？创建账号”注册普通用户。后台管理员登录不代替前台账号。注册入口仅在站点开放注册后出现；需要邀请码时，向站点管理员获取。

## 生成第一张图片

1. 打开“AI 生图”，填写主体、场景、构图、风格等描述。
2. 按需添加本地图片或本人素材库中的参考图，通用生图最多 6 张。
3. 选择可用模型、比例、清晰度和张数。选项由模型能力决定。
4. 核对预计积分并提交，等待任务完成后预览和下载。

切换页面不会自动取消后台任务。可在历史记录或“我的资产”查看结果，载入参数继续创作。重新生成是一次新的任务，会再次计费。

生成失败或部分成功时，以实际交付图片结算；未交付部分退回预留。图片一致性、商品文字和细节受模型能力影响，使用前请核对原图。

## 电商图片

从“电商工具”选择：

| 工具     | 用途                                               |
| -------- | -------------------------------------------------- |
| 商品主图 | 上传清晰商品图，设置背景、光线和构图               |
| 商品详情 | 按模块组织主视觉、卖点、细节和场景素材             |
| 爆款复刻 | 分别提供商品原图和参考构图                         |
| 产品精修 | 改善光影、材质和瑕疵，核对主体保留情况             |
| 服装组图 | 同款服装的多视角商品图，或结合模特照片制作上身效果 |

明确区分商品原图与构图参考，不应根据参考图替换商品身份。服装规划如支持识图，可先生成并检查逐张规划；也可手动编辑后再提交生图。

## 图片反推

从工作台或灵感页打开图片反推，选择自己的图片，按用途提取“还原画面”或“只提取风格”的提示词。结果可以编辑、复制、带入创作或保存到个人提示词。

该功能需要管理员配置支持图片输入的 Prompt 服务。分析和随后生图是两个独立操作，是否收费以站点提示为准。

## 素材与作品

“我的资产”分别浏览生成作品、上传素材和创作记录，支持搜索、收藏、项目整理、图片对比和下载。作品、素材与任务按账号隔离。

历史任务引用过的素材可能仅从列表隐藏，保留文件用于恢复创作配置；删除页面条目不一定代表立即物理删除所有关联文件。

## 提示词与预设

“我的提示词”保存本人内容，支持分类、标签、收藏、变量和版本。创作预设可保存模型和参数，再应用到新的创作；应用预设不会自动生成图片。

公共灵感库可匿名浏览、搜索和复制，登录后可以保存到个人提示词或带入工作台。风格段需要补充具体主体与场景；封面只是对应来源的示例，不保证所有模型产生相同效果。

## 分享与反馈

可以通过“分享提示词”提交内容与封面，管理员审核后才进入公共灵感库；奖励按站点配置执行。需要反馈问题时，使用页面中的“意见反馈”，描述操作步骤并按需附图。
