# 图片对比

在“我的资产”中打开图片预览，点击顶部“对比”，当前图固定为 A，右侧通过缩略图选择 B，无需先勾选两张图片。相关图片优先包含参考原图、同次生成结果和同项目作品；可搜索、切换生成作品/我的素材、筛选项目及加载更多。固定图会从另一侧的候选中排除。精修等带参考图的作品另提供“与原图对比”快捷入口。

选中后在同一个窗口进入对比，更换 A/B 也使用同一选图面板。已有对比时，选图面板内的返回按钮或 Esc 回到原来的对比；首次尚未选 B 时 Esc 关闭窗口。

工作台已有结果时，图片足够两张即可显示“对比”：包含本组结果、当前记录的参考原图和本次页面会话中的其他生成版本。浏览历史记录时，也能对比该记录的结果与参考原图。

## 查看细节

- 资产页默认并排，手机使用上下排列；工作台在手机上沿用默认滑杆，另一种模式为上下排列。
- 同步缩放支持相对适应尺寸的 1–8 倍，不等同于像素 1:1。放大后拖动画面、使用方向按钮，或聚焦画面后按方向键同步平移。
- 滑杆可拖动中间分割线，也可使用下方的范围控制；分割线支持左右方向键。
- “适应”或画面上的 0 键恢复缩放和平移，交换、更换图片与切换模式也会重置视图。
- Esc 关闭，关闭后焦点回到触发按钮。加载失败时可重试或选择其他图片。

图片采用完整原图与等比居中显示。尺寸或比例不同的图片会显示说明，滑杆提供视觉比较，不自动裁剪或像素配准。所有操作仅改变查看方式，不修改文件，也不会调用生成或识图服务。

## 实现与验证

共用对比弹窗按需加载；私有图片沿用账号鉴权和缓存，图片来源去重并限制为资产接口或无嵌入凭据的 HTTP(S) URL。更换图片时重建加载状态，防止旧图片带着新标签出现。

几何测试覆盖缩放范围、同步平移边界和滑杆坐标；来源测试覆盖商品/参考素材、去重和不支持的地址。页面回归使用既有图片，不产生付费 AI 请求。
