# 私有提示词与创作预设

左侧“我的提示词”提供两个视图，内容仅当前账号可见，与公开发现灵感分别保存。

## 提示词

- 新增、编辑、搜索、分类、标签、收藏和复制。
- 使用 `{{产品名称}}` 等变量；应用前填写所有变量，填写后的总字数也按目标工具限制。
- 从灵感卡片书签按钮、资产预览或图片反推结果保存到个人库。保存不会启用或发布公共灵感。
- 删除移到回收站，保留内容和版本，可以恢复。
- 编辑弹窗可载入历史版本，再保存为新版本。并发编辑检查版本号，发生冲突保留当前草稿，避免静默覆盖。

## 预设

在任意生图工具的顶部“提示词与预设”中保存当前模型、比例、清晰度、风格、图种与描述。工作台快选只显示当前工具的预设；个人库可以查看并应用所有工具预设，自动进入对应工具。

预设不包含上传素材、图片 ID、项目 ID、API Key 或其他服务密钥。服装预设保存图种、张数、拍摄风格与描述，使用时重新选择素材并确认逐图规划。可以在个人库编辑名称、描述、分类、标签、模型和常用参数；更复杂的图种组合在工作台调整后另存。

应用会回填描述与参数，保留当前上传素材，不自动生成或自动识图。纯参数预设保留当前描述。工作台提供撤销应用，模型不可用时提示配置对应服务，不自动换成其他模型。

页面间使用账号隔离的临时应用记录传递填写后的变量，10 分钟过期，成功应用后消费。网址只携带记录 ID，不放入完整私有提示词。刷新后含变量的记录需要重新从个人库应用。

## 接口与验证

`/v1/personal/prompts` 支持 kind、q、category、favorite、mode、taskType、trash 和游标分页；单条接口支持读取、保存、收藏、移入回收站、恢复与版本分页。内容保存在 personal_prompts，版本在 personal_prompt_versions；迁移不修改公共灵感库。

回归覆盖账号隔离、私有分类、版本冲突、70 个版本的分页、回收站恢复、预设参数和禁止保存素材/密钥字段。前端覆盖变量填写、替换字符、描述长度、预设参数和不可用模型处理，不调用真实 AI。
