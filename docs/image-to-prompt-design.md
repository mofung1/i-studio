# 图片反推提示词：首版设计方案

设计日期：2026-10-13。状态：用户已确认，首版已实现。本文件保留历史设计；2026-10-15 账号隔离后，前台反推仅保存到个人提示词，公共灵感内容由独立后台维护。使用说明见 [图片反推](image-to-prompt.md)，本文件保留设计取舍。界面草图见 [image-to-prompt-preview.html](../test/previews/image-to-prompt-preview.html)。

## 功能定位

从图片提炼可编辑、可复用的生图描述，服务于现有 AI 生图和灵感库。结果描述可见的主体、场景、构图、光线、配色、质感和风格。不能仅凭图片准确恢复隐藏的原始提示词、随机种子、模型版本或 LoRA，也不承诺生成完全相同的图片。

对本站生成且仍保留创作记录的资产，先提供“查看原提示词”；需要重新提炼风格或分析修改后的图片时再调用识图服务。

## 入口与页面布局

- AI 生图：在输入框工具区增加次级按钮“图片反推”，邻近“AI 优化提示词”；已上传参考图时可直接选择其中一张。
- 发现灵感：提供同名入口，分析后可填写标题和分类，保存为灵感草稿。
- 我的资产：图片操作菜单增加“反推提示词”；已有创作记录的图片优先提供“查看原提示词”。

所有入口打开同一个弹窗，不新增一级导航。桌面采用左右两栏：左侧原图、替换图片、分析模式和补充要求；右侧语言选择、可编辑提示词、折叠的画面分析。小屏变为上下排列，底部操作保持可见并为正文预留空间。

右侧主要操作为“应用到生图”；“复制”和“保存到灵感库”为次级操作。弹窗关闭后保留本次草稿。应用时保留用户既有输入：空输入框直接填入，有输入时选择“替换”或“追加”；应用后可撤销。是否把原图作为生图参考由独立选项控制，“只提取风格”模式默认关闭原图参考，避免混入原图主体。

## 首版交互

1. 单图上传、拖拽或粘贴，支持 JPG、PNG、WebP；原文件上限建议 10 MB，与现有资产上传一致。进入识图请求前压缩到不超过 5 MB，保留图片比例和方向。
2. 模式仅两种：
   - **还原画面**：描述主体、数量、姿态、场景、空间位置、构图、光线、配色、可见质感和整体风格。
   - **只提取风格**：描述媒介、线条、笔触、布光、色调、质感、构图原则和氛围，剔除原图具体人物、商品、品牌及画面文字。
3. 可选补充要求，例如“重点描述光影”“不要画面文字”。中文默认、英文可切换；一次分析返回两种语言，切换已有结果不再收费调用。
4. 一次返回主提示词与结构化分析。正文直接编辑；结构化分析默认折叠，分为主体、场景、构图、光线、色彩、质感、风格和可读文字，作为分析参考。正文编辑后不自动覆盖用户文字。
5. 等待显示真实状态“正在分析图片”，提供取消；失败保留原图和草稿并允许手动重试。重复点击不创建重复任务，替换图片后忽略旧任务返回的结果。
6. “应用到生图”仅填写配置；由用户点击生成按钮后开始出图。
7. “保存到灵感库”打开标题、分类下拉和内容确认。默认保存为未启用草稿，用户启用后才展示在发现灵感。原图作为封面需明确勾选，并提示启用后会出现在公开灵感库中。

## 与项目现有能力的衔接

已存在：

- `server/prompt.go`：登录鉴权、图片与文字组合输入、提示词服务能力检查和服务调用。
- `server/protocol_clients.go`：OpenAI-compatible Chat Completions，图片使用 Base64 传入。目前固定 `detail: low`，反推功能应允许按服务能力使用 auto/high，不能直接沿用低细节设置。
- `web/lib/image-file.ts`：图片压缩，当前默认长边 1280。建议反推普通图默认 1536，文字/纹理细节图可用 2048，并结合服务支持情况调整；保留透明背景或先按预览一致的底色合成。
- AI 服务设置和 Prompt 模板管理、资产上传、灵感分类与提示词 CRUD。

本次只读检查发现默认 Prompt 服务为 `deepseek-flash`，已启用且勾选 Vision，超时 60 秒。[DeepSeek 官方 Vision 文档](https://api-docs.deepseek.com/guides/vision/)确认该模型支持图片输入及 OpenAI-compatible 请求。是否能直接使用取决于当前接口平台的兼容性及额度；实际兼容性以实现阶段的真实识图验证为准。

## 后端方案

复用现有服务配置与队列设施，建立独立的分析任务类型，结果与生图任务分开存储和展示。

- `POST /v1/prompts/reverse`：创建任务，输入本人拥有的 `assetId`、模式、补充要求和请求标识；返回分析任务 ID。临时粘贴/上传图片先创建私有临时素材，不默认加入资产列表。
- `GET /v1/prompts/reverse/{id}`：查询本人任务的状态和结构化结果。
- 取消接口：取消本人待处理/运行中的分析任务，已完成结果保留至用户清除或到期。
- 队列处理：读取图片、执行一次识图请求、验证结果、持久化后返回。页面切换、弹窗关闭或轮询断开不改变后台任务状态；重新打开可以恢复结果。
- 状态：待分析、分析中、完成、失败、已取消。图片解码与尺寸检查由后端完成；只在服务端持有 API Key。
- 输出包含 `promptZh`、`promptEn`、`analysis`、`uncertainties`、`model`、`templateVersion`；可读取供应商返回的用量。格式不完整或截断时明确报错，不伪造成功结果，也不自动重复付费调用。
- 超时建议默认 120 秒并可配置，独立于图片生成超时。先对现有模型测时，再确定最终值。输出额度需提高到能容纳双语提示词及分析，不能沿用现有帮写固定的 800 tokens。
- 图中文字只作为分析数据，不作为可执行指令。看不清的文字和无法证实的商品参数返回“不确定”，不编造品牌、成分、认证或价格。
- 保存灵感封面需要扩展目前仅保存文字的新增接口，校验图片归属并复制为灵感封面；直接编辑正文不会丢失原图。

临时图片与分析记录建议保留 24 小时供恢复，保存到资产/灵感库时转为持久化。清理仅针对临时素材，不删除用户已保存图片。上传按钮旁说明图片会发送至当前配置的识图服务；第三方留存以该服务政策为准。

## 设置设计

在设置中增加“图片反推”功能配置：

- 服务选择：默认沿用现有 Prompt 服务，可指定另一个已启用且支持识图的 Prompt 服务。首版无需新增供应商协议。
- 分析超时、图片细节档位、临时结果保留时间。
- Prompt 管理的“图片反推”分组新增“还原画面”和“仅提取风格”两个模板，支持编辑、启停与恢复默认。
- 返回字段、登录与文件校验规则固定在代码中，保证自定义模板后界面依然能解析结果。

备选服务可使用支持图片输入的 Qwen 或 Gemini，通过各自的 OpenAI-compatible API 接入。相关说明：[Qwen 图像理解](https://www.alibabacloud.com/help/en/model-studio/vision)、[Gemini OpenAI compatibility](https://ai.google.dev/gemini-api/docs/openai)。实际输出质量应以项目样例测试为准。

## 需要准备什么

| 项目 | 首版需求 |
| --- | --- |
| 识图服务 | 优先验证当前 deepseek-flash；若平台不支持，再配置一个支持图片输入的服务地址、API Key 和模型名。密钥在设置中录入。 |
| 额度 | 一次识图请求按服务的图片/输入及输出用量计费；复制、编辑、切换已生成的语言不会再调用。再生图另计。当前无需承诺固定单次费用。 |
| 测试素材 | 建议 6–10 张用户可使用的代表图片：商品摄影、服装/人物、插画、海报文字、复杂构图；为每张标出必须保留的特征。 |
| 服务器 | 现有 Go、PostgreSQL、Redis、图片存储即可承担 API 版首版；无需为云端识图新增 GPU。 |
| 范围确认 | 建议先做单图、两种模式、双语、编辑复制、应用到生图和保存灵感草稿。批量、URL 导入、多模型输出语法和多个创意变体留待后续。 |

验收重点：可见特征是否遗漏或虚构、风格模式是否混入原图主体、文字是否乱猜、应用是否覆盖已有输入、切页后是否能恢复、重复点击是否重复收费。反推后的图片相似度测试作为后续单独评测，不在本次设计阶段消耗出图额度。
