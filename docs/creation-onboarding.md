# 首次创作引导与模型使用建议

L09 于 2026-10-23 完成本地开发。工作台使用当前可用模型配置，不绑定目前的模型名单。

## 描述示例与预设

空白结果区显示创作步骤和适合当前工具的描述示例：通用生图提供静物、插画与海报背景；电商按主图、详情、构图参考和精修分别提供需求；服装提供棚拍与自然光展示需求。

点击示例只填入空白描述，并展开设置、聚焦描述框。模型、比例、清晰度、张数和已有素材保持原样。已有文字时不显示示例覆盖按钮，清空描述后可再次选择。所有示例可继续编辑，不会自动提交生图或 AI 服装分析。

示例是描述预设；个人完整创作配置继续通过顶部“提示词与预设”保存、应用和撤销，不另建一套预设存储。服装仍需上传素材并核对逐张规划；电商的素材要求和模型兼容校验继续有效。引导不替代失败提示、历史记录或已生成结果。

## 后台配置使用建议

进入“模型与定价”编辑模型，在“使用建议（可选）”填写经过实际验证的适用场景，最多 200 字。说明是公开纯文本，留空不展示，不自动按模型名称生成评价。建议保持简短，避免填写服务密钥、私有配置或未经实测的质量、速度承诺。

工作台模型选择区域展示：

- 当前模型已填写的使用建议。
- 可展开的参考图能力、比例、清晰度与单张消耗，均读取接口配置。
- 单价使用站点积分单位；实际总消耗继续以现有生成前报价为准。

后台更改名称、说明、能力、价格或上下架状态后，刷新工作台读取新配置，无需修改前端代码。没有新增周期轮询。缺少说明或旧 API 未提供某项信息时，只展示已有信息；下架或没有可用主渠道的模型不进入公开列表。

## 数据与升级

`public_models.usage_hint` 由 `017_model_usage_hint.sql` 添加，默认空字符串，数据库和接口限制为 200 个字符。管理员保存时去除首尾空白，沿用模型事务、版本冲突和权限校验。公开能力接口增加 `usageHint`，复用已有 `priceMinor` 和 `capabilities`，不会公开渠道凭据。

业务 API 正常升级时先由现有迁移器应用该迁移，再部署配套前端。本轮仅在独立测试库迁移，未更新业务数据库或 Docker 服务。现有模型默认没有使用建议，需要管理员依据实际结果填写。

验收证据见 [L09 报告](../test/reports/workbench-l09-2026-10-23.md)。
