# 后台界面与使用

后台仍属于 `web/` Next.js 项目，沿用 `/admin` 路由、独立管理员登录和 Go API。没有单独的后台项目、端口或部署步骤。

## 页面结构

界面参考 [shadcn-admin](https://github.com/satnaing/shadcn-admin) 的圆角侧栏、轻量顶栏与灰白配色，通过官方 shadcn/ui Radix 组件适配现有 Next.js 项目。保留 iStudio 的导航、数据和权限逻辑，不引入模板中的演示业务。

- 工作空间：运营概览、用户与余额、生成任务。
- AI 与内容：模型与定价、AI 服务、系统提示词、公共灵感库。分类管理从灵感库内打开。
- 系统管理：意见反馈、网站配置、图片存储、运营设置、操作日志。
- 顶栏：常用页面入口、主题切换、配置入口与账户菜单。

侧栏支持收起为图标，小屏通过抽屉展开。`⌘/Ctrl + B` 收起或展开侧栏。账户菜单可返回工作台或退出后台；退出只清除管理员登录状态。

概览卡片读取现有 `/v1/admin/overview` 的真实统计。列表继续使用服务端分页与排序，保留列设置、行距切换、固定列和区域滚动。

## 配置生图

1. 登录 `/admin/login`，打开 **AI 服务 → 添加生图渠道**。
2. 选择 OpenAI 官方、Gemini 官方或兼容中转站预设，填写自己的 API Key、实际接口根地址与协议，保存。已有密钥编辑时留空即保留。
3. 点击 **测试连接**。**测试生图（可能收费）** 会在确认后调用实际 API，需填写服务商真实可用的模型 ID。
4. 打开 **模型与定价**，添加或编辑公共模型，设置名称、每张积分价格和生成能力。
5. 添加一个或多个渠道绑定，分别填写上游模型 ID，启用一个绑定并设为主渠道，保存模型。
6. 手动切换时选择另一绑定为主渠道并保存。后续新任务立即使用新渠道，已创建任务继续使用原渠道。

协议细节、官方地址和任务行为见 [AI 渠道配置](ai-channel-configuration.md) 与 [多渠道架构](ai-multi-channel-architecture.md)。

## 开发

在 `web/` 中使用原有 `pnpm dev`、`pnpm test`、`pnpm typecheck` 和 `pnpm build`。新增 UI 位于 `web/components/admin/ui/`，由 `web/components.json` 管理，避免覆盖前台现有组件。后台主题限定在 `.admin-shell` / `.admin-auth`，弹窗和菜单的 Portal 保持在该主题范围内。

## 系统提示词与网站配置

- **AI 与内容 → 系统提示词**（`/admin/prompts`）：搜索模板、修改指令、启用/停用或恢复默认内容。保存后对后续请求生效。反推配置的“编辑模板”会定位到对应模板。
- **系统管理 → 网站配置**（`/admin/site`）：修改网站名称、上传或移除 Logo，沿用原有品牌保存逻辑。
- **AI 服务**（`/admin/settings`）仅保留渠道管理与图片反推两个分类。原 `?tab=prompts` / `?tab=site` 入口会转到对应独立页面。

普通表单保存、切换、关闭及离开页面不再弹出未保存确认，也不拦截刷新或关闭浏览器。AI 服务与图片反推页签来回切换保留当前反推草稿，系统提示词切换模板保留各模板草稿；这些草稿仅在当前页面内暂存，离开或刷新后不保留。系统提示词的「填入默认内容」只更新表单，仍需点击「保存」才生效。

## 页面标题与列表

意见反馈位于「系统管理 → 意见反馈」（`/admin/feedback`）。列表默认待处理，支持搜索、状态筛选和分页；详情可查看正文、来源页面及最多三张私有附件，点击图片可放大，支持标记已处理或恢复待处理。使用说明见 [意见反馈](feedback.md)。

用户投稿审核位于「AI 与内容 → 用户投稿审核」。管理员可查看所选封面、退回原因与版本，审核通过时可选奖励整数积分；发布和奖励同步提交，同一投稿不重复奖励。公共灵感库中的投稿提供审核入口。投稿开关、每人每日次数也在审核页配置，详见 [投稿与审核奖励](inspiration-submissions.md)。

后台业务页面统一使用简洁页名，已移除「页面说明」及其折叠内容。字段提示、配置状态和必要的操作说明保留在对应功能旁；登录与权限提示仍用于完成登录和鉴权。

列表默认使用紧凑行距。列设置支持键盘操作、固定列保护和恢复默认，显示列与行距按列表保存在当前浏览器；不保存业务数据或登录凭据。翻页显示实际记录范围，并可输入页码直接跳转。搜索账号与刷新、添加操作排列在统一工具栏中。

页面搜索与 `⌘/Ctrl + K` 已移除；菜单不再单列“灵感分类”，公共灵感库内的“分类管理”继续可用。

## 间距规范（2026-10-22）

后台间距变量限定在 `.admin-shell`，不改变前台的布局规则。

| 用途                           | 桌面 | 手机（宽度不超过 767px） |
| ------------------------------ | ---- | ------------------------ |
| 页面横向边距、卡片和弹窗内边距 | 24px | 16px                     |
| 页标题到内容、主要区块之间     | 24px | 20px                     |
| 表单字段之间                   | 20px | 16px                     |
| 标签到输入框                   | 8px  | 8px                      |
| 运营设置的大分组之间           | 32px | 24px                     |
| 表单文本输入框高度             | 40px | 44px                     |

概览通过统一的内容容器排列监控、统计、额度和准备事项，不依赖卡片各自的外边距。运营设置移除旧表单与 Field 组件叠加的间距，注册开关集中排列。模型测试比例和档位使用与其他字段一致的上下排列；渠道卡片的标题、输入与操作之间保持明确间隔。

存储弹窗只保留一组取消/保存操作，「可选」提示与字段名同行，访问密钥和私钥在桌面成对排列、手机单列排列。AI 服务在窄屏将操作按钮换到独立行；灵感库手机筛选区按搜索、双筛选、操作分三行，列表分页统一排列并保留容器内横向滚动。

## 弹窗操作规范（2026-10-25）

前后台弹窗统一使用 `DialogActions`：取消、关闭等次要操作在前，保存、提交、通过等主操作在最右。窄屏不足时允许换行，每行靠右，主操作仍排在最后；手机按钮最小高度为 44px。状态文字和已选数量可留在左侧，不与操作按钮抢位置。

投稿、审核、私有提示词等长表单正文独立滚动，固定底栏通过原生 `form` 属性关联表单，保留必填校验和提交行为。模型、渠道、存储等原有编辑表单采用粘性底栏。顶部关闭图标、图片缩放与对比工具、列表内操作仍放在对应内容旁。

后台弹窗仅对透明度和位移执行过渡，避免调整视口时宽度缓动导致短暂超屏。四种屏宽、当前页分享和奖励审核的实际验收见 专项报告（历史记录，可从 Git 历史查看）。

用户投稿审核页的搜索框、审核状态、搜索与刷新在桌面端同排，统一 40px 高度；小于 768px 时搜索框单独一行，其余三个控件同排，统一 44px。投稿设置沿用 24px / 16px 的卡片内边距，数量输入框固定 88px，保存按钮靠右。后台下拉箭头使用文字色令牌，避免与浅色背景混在一起。验收见 投稿页布局记录（历史记录，可从 Git 历史查看）。

全站复查补充：分页将页数与翻页操作分组，手机允许换行；公共灵感库筛选控件在窄屏重置宽度，避免重叠，文字按钮保持单行。共享搜索图标和确认弹窗辅助文字使用后台 `muted-foreground`，保持两种主题下可读。全站主题切换使用不阻挡操作的短淡入过渡。范围与证据见 全站样式检查（历史记录，可从 Git 历史查看）。

图片反推的页面内底栏独立于弹窗按钮组：桌面状态文字与按钮分列，手机分行，按钮靠右；底栏按文档流排在全部配置之后，不吸底覆盖正文。样式验收需同时检查状态文字被压缩、底栏遮挡和按钮碰撞，详见 [布局验收规范](ui-verification.md) 与 修复记录（历史记录，可从 Git 历史查看）。

删除 AI 服务、停用账号及真实收费生图测试使用统一的站内确认弹窗，说明对象、后果或收费范围；取消在前，执行按钮在右下角。启用账号直接执行。确认弹窗支持明暗主题、键盘焦点限制、Escape 取消以及关闭后返回触发按钮；内嵌确认只关闭自身，不关闭模型编辑器。普通校验、保存结果与请求错误继续在表单内展示。全局原生弹窗扫描和实际验收见 确认提示清理报告（历史记录，可从 Git 历史查看）。
