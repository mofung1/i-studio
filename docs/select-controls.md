# 全站下拉选择框

资产筛选、项目移动与整理、私有提示词与预设、图片对比、灵感管理、工作台及 AI 设置共用 `components/ui/select.tsx`，不再混用可见的原生 select。全站采用黑白灰背景、8px 圆角、相同的箭头、菜单和选中状态；颜色来自主题变量。

## 尺寸与状态

普通表单和列表筛选使用默认 40px；紧凑模型选择使用 sm（36px），与 44px 输入框同排的设置表单使用 lg（44px）。手机与触控设备上的选择框和选项至少 44px。页面只定义宽度、网格和布局，外观由 globals.css 的共享 Select 样式控制。

触发框的已选文字单行省略，勾选图标位于菜单右侧，文字不会被覆盖。菜单长文字可换行；长列表提供滚动按钮，菜单高度受可用视口限制。选中、悬停、键盘焦点、禁用、占位及错误状态分别处理。黑白主题和减少动态效果使用同一套规则。

## 使用约定

- 标准组合使用 Select、SelectTrigger、SelectValue、SelectContent 和 SelectItem；没有显式分组时，内容组件自动补齐 Group。
- 简单列表可以使用 LibrarySelect，传入 label、value、options 和 onChange；它与标准组件使用同一套实现。
- 弹窗中默认将菜单挂到触发框所属的 dialog/popover，避免菜单落到浏览器原生顶层弹窗后面。需要特殊容器时仍可传 portalContainer。
- Escape 只关闭当前菜单，关闭后由 Radix 恢复触发框焦点；不要将菜单 Escape 传给父弹窗的关闭处理。
- 不在页面中单独重设选择框颜色、边框、圆角、字体或菜单选项样式。需要尺寸差异时显式使用 size。

## 验证范围

代码扫描确认所有 10 处可见原生下拉框已替换。隔离 DOM 回归覆盖自定义弹窗中的 Escape 与焦点返回、原生 dialog 内菜单容器与选项回填、受控展开状态。49 项前端测试、TypeScript 检查和 Next.js 生产构建通过。当前浏览器工具未允许读取页面，手机、夜间模式和实际弹窗位置尚未完成真实浏览器复测。
