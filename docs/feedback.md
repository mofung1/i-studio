# 意见反馈

前台提供简单的反馈弹窗，填写内容并可选附上最多 3 张图片。无需填写标题、分类或联系方式。

## 入口与提交

- 工作区侧栏底部、个人中心上方显示「意见反馈」；侧栏收起后保留图标和提示。手机展开导航后可见。
- 登录后的头像菜单提供同名入口，官网及工具介绍页的页脚也可打开弹窗。
- 未登录时在弹窗内提示登录。内容必填，最多 2000 字；图片选填，支持 JPG、PNG、WebP，每张不超过 5MB。
- 选择后可预览、移除和重新选择图片。底部取消、提交按钮靠右；关闭、取消和 Escape 直接关闭，提交过程中阻止关闭及重复操作。
- 文字和附件一次提交，失败时保留当前表单；同一内容重试沿用提交编号，避免重复记录。修改内容或图片后重新生成提交编号。提交成功后显示「反馈已收到，感谢你的建议」。

每个账号按北京时间每天最多提交 5 条，已成功提交的同一编号重试不占额外次数。反馈不消耗积分。

## 后台处理

后台「系统管理 → 意见反馈」（`/admin/feedback`）默认展示待处理记录。支持按全部、待处理、已处理筛选，按内容、编号、用户名搜索，以及分页和刷新。

点击「查看反馈」可读取完整内容、作者、提交时间、来源页面、处理状态和图片，图片可放大。管理员可标记已处理或恢复待处理，状态变更写入操作日志。状态只表示管理员的处理标记，不自动向用户发送通知。

## 数据与附件

- 迁移 `020_feedback.sql` 新增 `feedback` 和 `feedback_images`，不修改现有资产或积分表。
- 自动记录打开弹窗时的页面路径，不保存查询参数和片段，避免将提示词、令牌等页面参数带入反馈记录。
- 附件独立于「我的资产」，不占用户素材库额度，也不会加入公开灵感库。本地目录为 `server/storage/uploads/user/YYYYMMDD/feedback/`，日期按北京时间；使用云存储时沿用当前存储后端及后端标识。
- 附件通过登录校验接口读取，仅提交者本人和独立后台管理员可访问。接口使用 `no-store`；不向前端返回存储密钥或公开 CDN 地址。
- 服务端再次校验正文长度、图片数量、文件大小、真实图片类型及尺寸。一个请求最多 16MiB；单图最多 1 亿像素。
- 保存文字、附件记录与每日次数检查在事务中完成；存储失败回滚记录并清理本次写入的文件。未提交前图片只在浏览器本地预览，关闭时释放预览地址。

## 接口

| 方法与路径                                    | 用途                                                                              |
| --------------------------------------------- | --------------------------------------------------------------------------------- |
| `POST /v1/feedback`                           | 登录用户提交 multipart 表单：`content`、`pagePath`、`requestKey`、0–3 个 `images` |
| `GET /v1/feedback/:id/images/:position`       | 本人读取反馈附件                                                                  |
| `GET /v1/admin/feedback`                      | 后台分页、筛选和搜索                                                              |
| `GET /v1/admin/feedback/:id`                  | 完整反馈及附件访问路径                                                            |
| `PATCH /v1/admin/feedback/:id`                | 设置 `status` 为 `pending` 或 `handled`                                           |
| `GET /v1/admin/feedback/:id/images/:position` | 后台读取附件                                                                      |
