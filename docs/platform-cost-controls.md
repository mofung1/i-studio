# 平台额度、存储与输出核验

2026-10-22 开发，对应 L04、L05。入口为后台「运营设置」「运营概览」和「模型与定价」。测试范围与结果见 [专项报告](../test/reports/platform-cost-output-2026-10-22.md)。

## 默认策略

| 配置 | 默认值 | 行为 |
| --- | --- | --- |
| 平台同时辅助请求数 | 4 | AI 帮写、图片反推、服装分析共享，按数据库中的有效处理租约计数 |
| 平台每日辅助请求总数 | 1000 | 按北京时间自然日计算，已开始处理的失败请求也占用次数 |
| 每日注册赠送总预算 | 1000 积分 | 仅统计当天实际入账的注册赠送；不足以全额赠送时暂停新注册，不少发约定数量 |
| 每日积分消耗告警阈值 | 1000 积分 | 今日结算消耗达到阈值时在运营概览提醒，0 关闭；不取消已创建任务 |
| 每账号存储额度 | 1024 MiB | 上传素材、生成作品、历史引用的隐藏素材和反推暂存共用 |
| 邀请注册 | 默认关闭 | 可选开启，管理员设置或更换邀请码；只保存哈希，不返回原文或写入操作日志 |

已有配置缺少新字段时使用以上默认值，原积分名称、注册赠送数量及单用户限制继续保留。实际运营前应根据上游额度和可用存储调整。平台积分、辅助次数和供应商货币费用分别记录；积分消耗告警不是 API 费用告警，也不代表收入或利润。

## 辅助服务与注册预算

辅助请求在开始处理时通过数据库事务取得平台名额并写入每日计数。同步 AI 帮写及服装分析释放名额后响应；图片反推在 Worker 开始处理时取得名额，并发繁忙时回到队列，日额度耗尽时明确失败。正常结束或取消后释放；进程退出而没有释放时，租约在 11 分钟后过期，不永久占用名额。单次处理上下文最多 10 分钟，原更短的服务超时仍有效。原单用户每小时限制继续生效。

注册在同一事务中重新读取当前策略、校验邀请码、锁定平台赠送预算并创建用户、钱包及赠送流水。多账号并发不能超发；失败时没有半创建账户。赠送为 0 时不消耗预算；赠送大于 0 而预算为 0 或不足时拒绝注册。变更数量只影响后续注册，不追溯已有账户。

运营概览显示今日辅助次数、当前并发、注册赠送和存储用量；赠送或辅助日额度达到 80%、积分消耗达到配置阈值、账号存储已满时出现站内提醒。本次未接入邮件、短信或外部消息通知。

## 存储口径

数据库按账号统计原图的登记字节，写入前进行账号级串行检查，资产表及反推暂存表还有数据库触发器保护，避免并发上传或生图突破上限。达到上限时不能创建新生图任务；生成过程中实际图片导致超限时，保留此前已交付图片，按交付张数结算并退回剩余预留。

同账号重复上传已有素材复用原资产，不重复占用；被历史引用而仅隐藏的素材仍占用。物理资产记录删除和反推过期清理后释放登记额度，降低上限不会删除现有数据。个人中心可查看用量和上限。

旧反推暂存没有记录真实字节长度，升级时按原上传上限预留：原图 10 MiB，存在分析图时再加 5 MiB；个人中心会标注这部分为估算预留，正常删除或过期后释放。新任务按真实字节登记。缩略图缓存、未登记的孤立对象、数据库及系统配置不计入账号原图额度；服务器磁盘与云桶实际用量监控需后续独立安排，不在用户限定的本轮 L06 范围。

## 输出与供应商费用核验

生成任务新增单图 `elapsed_ms`；任务和历史接口返回本人图片的实际宽高、字节数和耗时。前台标记「请求档位」，图片工具栏显示「实际像素」，已保存数据存在时显示该张生成耗时。耗时衡量上游生成/等待阶段，历史未知值不补造。后台任务列表同样区分请求参数与实际输出，不返回图片正文或提示词。

后台模型编辑器可选择测试比例、1K/2K/4K 请求档位，每次明确确认后只生成一张。收到图片后通过现有安全下载及格式校验读取实际宽高，不放大、不修改图片字节；测试成功或失败都保存独立的通道核验记录。展开「输出尺寸与费用核验记录」才读取最近 30 项记录，查看和录入费用不会再次调用 AI。

费用记录区分「估算费用」与「供应商账单费用」，未知留空、真实免费填 0，金额最多六位小数，并记录币种和来源说明。账单字段是管理员录入，不能当作已经由平台自动对账。记录或更改费用不调整模型单价、不修改用户余额，后台操作日志会记录费用更新。基于实际账单确定是否分辨率分档定价，仍由运营者明确决定。
