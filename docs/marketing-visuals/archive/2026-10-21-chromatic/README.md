# iStudio 展示素材

当前版本：2026-10-21，高彩度当代影像。钴蓝、珊瑚橙与少量青柠色，结合雕塑建筑、时装摄影与商业静物，页面界面仍沿用黑白主题。

本轮使用官方内置 ImageGen 完成 14 次生成／参考编辑：10 张新场景、同商品护肤品场景编辑、同香水精修，以及静物和时装的两张横版重构。所有正在使用的首页、工具页和分享图片都已替换。工具区保留五项，已移除参考图创作演示。

图片是 AI 概念作品，未作为 iStudio 产品内实际任务、用户案例或商品保真保证。首页统一在底部说明，减少每幅图片下重复的脚注。商品对比使用同一张基础图作为编辑输入，保留商品轮廓、位置与构图。

## 文件

- `web/public/images/marketing/chromatic/`：13 张主素材与裁切（约 1.25 MiB）。
- `web/public/images/marketing/tool-showcase/chromatic-*.webp`：5 张功能预览（约 0.39 MiB）。
- `prompts.json`、`sources.json`、`manifest.json`：完整提示词、工具原始路径、参考关系、发布尺寸和 SHA-256。
- `tool-showcase/`：功能预览的同类记录，其中两张直接裁切新场景，三张为参考编辑。
- `archive/2026-10-21-neutral/`：上一版中性色素材的来源记录，保留追溯。
- `test/artifacts/marketing-chromatic-2026-10-21/`：工作区原图与检查截图，不提交 Git。

重新编码：在 `web` 下运行 `node scripts/prepare-marketing-assets.cjs` 和 `node scripts/prepare-showcase-assets.cjs`。脚本仅缩放、裁切和编码已有图片，不下载、不生成、不读取模型密钥。原始输出路径缺失时读取工作区归档。

## 页面与动效

保留大标题叠压与滚动展开、五项工具预览切换、商品滑杆和原生横向画廊。删除重复标题、双语说明、图片脚注、辅助提示和首页三步说明。宽度至少 1000px、高度 620–739px 的桌面使用紧凑叠压布局；手机、矮窗口和触屏保持自然文档流。减少动态偏好、键盘操作与无 JavaScript 的内容保持可读。

## 验证

TypeScript、255 项前端测试、格式检查和生产构建通过。最终首页 First Load JS 约 119 kB。生产预览检查了五项工具切换、电商导航定位、商品滑杆和 1280×720 首屏；390×844、1024×768、1440×900 使用无脚本 SSR 快照做布局检查。没有进行真机测试或实际消耗积分的产品生图。截图和检查记录位于上述测试产物目录。
