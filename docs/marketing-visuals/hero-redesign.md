# Hero：编辑式叠压与滚动展开 · 2026-10-21

## 本次范围

仅优化 Hero 的构图、对比度与滚动时序。保留现有云海城市素材、单个服务端 H1、正文与 CTA、移动端纵向布局和下一章节。首页其他区域、Metadata、Sitemap、Robots、导航、工作台及后端均不改动。

运行代码改动：

- `web/components/marketing/editorial-hero.tsx`
- `web/components/marketing/hero-canvas.tsx`
- `web/styles/marketing-hero.css`

## 构图与层级

原来约 54% 宽的右侧配图扩大为约 69% 视口宽度，初始左边界在 28vw，右边距 3vw。图像是主要视觉，不再与文本平均分栏。

标题使用现有系统中文无衬线，桌面 700 字重、72–132px 的响应式字号，第一行位于图片上方，第二行跨越图片左边缘。画布为背景层，完整矩形主图为中景，标题及 CTA 为前景。文字列保留独立的说明和操作区域。

标题没有背景色。照片内的浅色字形由 `aria-hidden` 的装饰文字层提供，其矩形裁切范围严格跟随图片与标题的交集。此层只绘制文字，不挖空、覆盖或改变主图边界。实际 H1 仍只有一个。照片左侧使用轻量明暗处理增强大字对比度，随后跟随标题退出，未引入页面装饰色、额外标签或其他素材。

现有主图足以容纳新的构图，没有重新生成图片。仍标注“AI 视觉概念示例”，不宣传为 iStudio 真实生成任务。

## 动画

项目没有安装 GSAP，继续使用已有原生 sticky + passive scroll/RAF，不添加依赖。滚动直接决定矩形 clip-path、等比例 transform 和 opacity，支持原路反向恢复，不积累动画实例。

- 初始：完整大图与超大标题叠压；CSS 已能呈现正确画面。
- 约 30%：画框向左延伸、等比例放大，标题轻微向左上移动并淡出；浅色字形仍跟随移动中的图片边界。
- 约 70%：标题已退出，图片接近全屏，最高建筑保持可见。
- 后段：画框完全展开，接续原有 AI 创作介绍。

说明和 CTA 比标题更早退出，避免图片扩展到操作区域后出现可读性或点击冲突。动画仅在桌面精确指针、足够视口高度且未启用减少动态效果时开启。

初始画框和图片平面共用 CSS 几何变量。控制器读取稳定的布局定位元素，不再使用独立的魔法缩放常数；保留亚像素精度。新构图上下边距不对称，因此初始 CSS 下边距也使用“画布高度减去图片顶部与高度”，与客户端测量一致。已通过禁用 JavaScript / 启用 JavaScript 的初始边界比较。

`useLayoutEffect` 初始化，ResizeObserver 监听画布及导航；resize/pageshow 后刷新几何，卸载时清理事件、观察器与 RAF。

## 移动端与可访问性

手机、触屏、窄窗口或矮窗口继续采用纵向自然文档流，主图 16:9，不强制叠压或固定滚动。桌面减少动态效果时保留静态构图。浅色装饰字形不参与辅助技术读取，也不会截获点击。正文、H1、图片说明和内部链接均保留在服务端 HTML。

## 最终局部精修

本轮没有改动组件 DOM、素材、CTA、滚动时序或其他首页区域。运行代码仅修改 `marketing-hero.css` 与 `hero-canvas.tsx`：

- 标题响应式字号从 `clamp(76px, 8.2vw, 140px)` 改为 `clamp(72px, 7.7vw, 132px)`，三个目标桌面宽度实际缩小约 6.1%；行高仍为 1.1。
- 桌面字距从 -.065em 改为 -.06em，使初始图片边界接近“于”和“画”的字间；移动端保留旧字距。
- 图片顶部公式减少 48px，连同标题变化实际向上移动约 54–56px；同步放宽高度上限以保持原有下边距，图片宽度仍约 69%。
- 既有浅色装饰字形层增加 4–8px 的向内渐变遮罩；控制器只新增同步边界变量与清理变量两行，位置/缩放/透明度的进度逻辑不变。
- H1、可访问文本数量、矩形画框及移动端排版保持原样。

四种目标尺寸的实际浏览器截图、精修前后字形坐标与滚动回归脚本在 `test/artifacts/hero-polish-2026-10-21/`。TypeScript、255 项测试、格式检查、本地及 Docker 生产构建通过。33000 生产预览的四种视口、11 个桌面滚动位置、反向、刷新、窗口缩放、SSR 和入口回归均通过。
