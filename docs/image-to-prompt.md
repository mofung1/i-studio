# 图片反推提示词

从图片提炼可编辑的创作描述，可用于下一次生图或保存为灵感草稿。功能需要登录、PostgreSQL、图片存储，以及已启用且支持图片输入的 Prompt AI。使用现有服务配置，无需新增 GPU。

## 入口与使用

- **AI 生图**：画面描述工具区的「图片反推」。已有多张参考图时，可选择其中一张分析。
- **发现灵感**：顶部「图片反推」。分析后可复制、保存草稿或带入 AI 生图。
- **我的资产**：打开本人生成图片的预览，点击「图片反推」。已有生成记录还提供「原提示词」，查看原记录无需识图调用。

上传、拖入或粘贴单张 JPG / PNG / WebP，原图不超过 10 MB、1600 万像素。选择模式后点击「开始反推」：

| 模式 | 输出重点 | 原图作为生图参考 |
| --- | --- | --- |
| 还原画面 | 主体、场景、位置、构图、光线、色彩、材质与风格 | 默认勾选，可关闭 |
| 只提取风格 | 摄影或绘画语言、光影、色调、质感、构图原则和氛围 | 默认关闭，可开启 |

一次识图同时返回中文和英文。风格模式按媒介、构图原则、光线、配色、质感五个双语分项组合提示词，不直接使用整幅画面描述。切换语言、编辑、复制已有结果不会重新请求服务。「画面分析」默认折叠，不确定的文字或细节单独列出供核对。反推用于提炼可见特征，不能准确恢复隐藏的原始提示词、随机种子或生成参数。

「应用到生图」填写配置，由用户点击生成后才出图。有现有描述时可替换或追加；工作台提供撤销。原图是否加入生图参考单独控制。重新分析、切换历史记录若将覆盖已编辑的文本，会先要求明确选择；刷新后可恢复未过期记录及当前双语草稿。

「保存到灵感库」确认标题、分类和正文，支持就地新增分类。默认存为**未启用草稿**，到管理提示词中确认并启用后才公开展示。原图作为封面需单独勾选；复制的封面不受反推临时记录清理影响。本站已启用的灵感内容可以公开浏览。

## 设置

进入「后台 → AI 服务 → 图片反推」。仅管理员可修改本站共享配置。

| 配置 | 默认值 | 范围与含义 |
| --- | --- | --- |
| 识图服务 | 默认 Prompt AI | 只能选择已启用、支持 Vision 的 Prompt 服务 |
| 分析超时 | 120 秒 | 15–600 秒；独立于生图超时及 Prompt 服务原有超时 |
| 图片细节 | Auto | Auto / High / Low；服务是否支持这些档位取决于接口兼容性 |
| 临时结果保留 | 24 小时 | 1–168 小时，从提交开始计时；对新任务生效 |

分析图保留比例，普通档位长边最多 1536、高细节 2048、低细节 1024；超过大小上限时进一步缩小，分析文件不超过 5 MB。服务端压缩会先应用 EXIF 方向信息。上传原图与分析图分开保存，预览、带入生图参考、灵感封面使用原图。资产入口由服务器准备分析图。

在「后台 → 系统提示词 → 图片反推」修改「还原画面」「只提取风格」两条模板，支持启停及恢复默认。每个任务保存模板快照；修改对新任务生效。停用相应模板后不能提交该模式。JSON 字段、双语要求和格式校验由程序管理；两种模式使用各自的输出约束，对外仍返回同样的任务结果结构。

## 后台任务与数据

任务状态为待分析、分析中、完成、失败或已取消。关闭弹窗、切换页面或刷新不取消后台分析；重新打开可查询本人最近 12 条未过期记录。每账号最多 2 个进行中的分析，服务器有 2 个独立识图 worker。

每个任务最多执行一次识图调用。网络提交重试使用同一请求标识，防止重复创建或收费；服务失败、格式不完整和超时不会自动重复调用。「重新分析」会创建新的任务并再次计费。取消会终止服务器请求，但已发送的调用是否计费由接口平台决定。

任务记录、原图与分析图仅本人凭登录访问，不加入公共资产列表。默认保留 24 小时；到期后不可再访问，并由后台定期清理。点击「清除这次分析」可提前删除记录和临时图片；进行中的任务需先取消。已保存的灵感和封面继续保留。图片发送至用户配置的识图服务。

异常中断的分析在原超时窗口结束后标为失败，不自动重放收费请求。识图成功后的短暂数据库写入失败会有限重试保存结果，不重复调用模型；数据库长期不可用时仍可能无法保留结果。

## API

下列接口需要 `Authorization: Bearer …`，私有响应使用 `Cache-Control: no-store`。设置为本站共享配置，其余任务和图片按账号隔离。

| 方法与路径 | 作用 |
| --- | --- |
| `GET /v1/prompt-reverse-settings` | 配置、服务是否可用、原因、名称和模型 |
| `PUT /v1/prompt-reverse-settings` | 保存 `{endpointId, timeoutSeconds, imageDetail, retentionHours}` |
| `POST /v1/prompts/reverse` | multipart 创建任务，返回 `202 {task}` |
| `GET /v1/prompts/reverse` | `{tasks}`，本人最近 12 条未过期记录 |
| `GET /v1/prompts/reverse/{id}` | `{task}`，查询状态与结果 |
| `GET /v1/prompts/reverse/{id}/image` | 本人任务的原图二进制 |
| `POST /v1/prompts/reverse/{id}/cancel` | 取消本人待处理或运行任务，返回 `{task}` |
| `DELETE /v1/prompts/reverse/{id}` | 清除本人非进行中的任务及临时图片 |

创建字段：`requestId`（8–100 字符）、`mode`（`scene` / `style`）、`requirements`（选填，不超过 2000 字），以及 `image` 文件或本人拥有的 `assetId`。可选 `analysisImage` 不超过 5 MB；总请求体不超过 16 MB。相同请求标识与相同输入返回原任务；标识相同、输入不同返回 409。

任务返回 `id`、`status`、`mode`、`requirements`、`imageUrl`、图片名称/宽高、模板版本和创建/更新/到期时间。完成后 `result` 包含 `promptZh`、`promptEn`、`analysis`、`uncertainties`、`model`、`templateVersion`；失败使用 `errorMessage`。供应商密钥、存储路径、内部执行标识和系统指令不会随任务返回。

新增灵感时，可选 `reverseTaskId` 从本人已完成且未过期的分析复制封面。跨账号记录、过期记录和未完成记录不能用作封面。

账号隔离后，反推使用前台用户会话，结果可保存为个人提示词；不再从此弹窗写入公共灵感库。公共内容由独立后台维护，后台会话不能读取前台反推原图。
